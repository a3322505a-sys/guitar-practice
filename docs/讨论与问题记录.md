## 3. 设置与行为规格

### 3.1 音阶练习

**2026-10-11 追加要求已实施（v54）：** 用户认为「范围与显示」太复杂，并明确“练习思路保留，去掉繁琐的选项”。六类练法及各自路线保留，局部／完整音域保留为一八度／整型音域；删除手动逐弦、反向与显示选择及其展开入口，采用全六弦、音名显示和各练法默认顺序，往返仍包含双向；「换起点」的级数直接随练法显示。下文原方案中的弦范围、显示选择与反向入口仅作为 v53 历史设计，当前不再提供。

将“练什么、怎么弹”改为“练习方式”，常用区只显示：

| 选项 | 目标行为 |
| --- | --- |
| 音阶往返（默认） | 一轮内低到高再回到低；转折处最高音只弹一次。选择反向时改为高到低再回到高，不能仍只播放单向路线 |
| 三度跳进 | 保留调内 1—3、2—4、3—5……的编排，不改为固定半音距离 |
| 指型连接 | 保留相邻指型的实际连接路线与可用条件；路线必须进入下一指型，不能用名称掩盖不可连接的组合 |

其他设置：

- “主音与八度”“三音模进”“换起点”放入“更多练法”。首期保留“换起点”的现有行为，暂缓合并为通用参数，避免给三度、模进和连接引入未经定义的边界行为。
- 范围文案改为“一八度／整型音域”，节奏文案改为“每拍1音／每拍2音”。沿用现有默认一八度，不自动扩大用户选定弦范围；不适用的控件继续隐藏。
- 弦范围、起点级数、反向和音名／级数显示仍按练法适用性收进“更多”；起点级数只随“换起点”显示。
- La 三弦4品提供一句伸指或轻微移位提示，不新增独立必练短句，不改整个指型的音位数据。
- 本期不为音阶页另建歌曲短句入口，避免与短句页重复。
- 单独“上行／下行”不新增常用入口，首期暂缓。

### 3.2 和弦学习与短句应用

一级导航为「音阶／和弦」。和弦页默认进入「和弦学习」，页内提供次级「短句应用」。学习顺序参考 [FretFlow](https://github.com/iecg/fretboard-app/blob/main/README.md) 的音阶、和弦音、指法和声音相互对应，再进入和弦进行与实际应用；本地工程按其思路独立实现，不将原项目全部功能描述为已实现。

- 基础和弦学习直接选择已有和弦，展示实际指法内的组成音与音名，可点音试听、听整和弦，再用示范和跟练逐弦检查。和弦事实、显示、发声共用同一份指法；省略音、转位低音和 X 弦不能用完整和弦模板补出。
- 和弦指法图居中，弦距、品距和圆点使用统一缩放，四品网格保持正方形。保留根音、空弦／禁弹弦、手指编号、当前音高亮及正确点击位置。
- 「短句应用」设置中选择已收录短句，当前为无夹《嘘月》S01。预设固定段落、弦品、和声、时值、奏法与演奏条件，隐藏第二和弦、每和弦拍数等不适用控件。
- 基础学习摘要显示所选和弦及学习方式；短句摘要显示短句名、类别、段落和演奏条件，伴奏展示当前及下一指法。未来单音素材应显示当前及下一音位。
- 「两和弦转换」「规则下拨」「简单分解」暂不恢复为并列常用设置；短句承接进行应用，但不能替代基础和弦学习。本期不新增自定义和弦进行编辑器。
- 未来按同一方向逐步补充全指板和弦音叠加、根音与性质选择、指型联系及声部连接；这些尚未实施，不能作为本轮完成项。
- BPM、循环次数、声音开关继续集中在“速度与播放”。只打开设置不停止播放；实际改变练习内容、速度或循环结束旧序列，声音开关即时生效。
- 跟练、听示范、撤提示、指板与六线谱切换沿用现有入口。

## 7. 验收与完成标准

- **设置：** 音阶常用区只展示三个练法；和弦为一级入口且默认基础学习，短句为页内次级应用入口。基础和弦选择与逐弦检查直接可用；短句只展示已收录类别。不适用参数隐藏，原“速度与播放”行为不回退。
- **路线：** 往返实际包含双向且转折点不重复；三度仍在调内；指型连接跨入下一型且保留不可用组合提示；La 三弦4品 B 保留。
- **音乐：** 首批实际收录段落能追溯指定源谱，逐音核对弦品、音高、时值、休止、延音、和声与技巧；原谱片段和改编练习有清楚标识。
- **显示与声音：** 变调夹位置及发声一致，当前／下一目标与谱面对应；单音练习不显示旧两和弦状态；多音、句尾和循环节拍准确。
- **回归：** 指板／六线谱切换不重播，旧序列在内容变更后结束；暂停、后台、恢复、预备拍、循环与声音开关按现有约定工作。必要自动验证覆盖往返、音高映射、素材节奏与循环、状态恢复；不为改文案堆叠测试。
- **设备与实用性：** 本地构建、渲染和 PCM 检查分别记录；真机安装、音画同步及实际练习的自然度另验。缺少设备或实弹反馈时保留未验证项，不以构建通过替代。
- **交付：** 最终清单、改编差异、来源和未解决项有记录。发生素材延期时不自动放入未核谱或无关通用练习凑数；首批四条全部达标前不能称方案全部完成。
