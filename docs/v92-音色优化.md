# v92：独立音色优化

基线：`main` 的 `2bec43c` 与开放 PR #13 / v91 的 `b02fd12`，后者已包含前者。
独立分支 `codex/alphatab-tone-v92`；主目录 v82 未提交工作及 v91 工作目录保留。
版本 v92 / 4.1.0-local44-alphatab，沿用包名、长期签名及用户资料。

## 音色与音量

- 复用全部 22 份旧 `guitar-nylon` PCM，离线转为 SF2 的 bank 0 / program 24
  （零基，GM #25）。保留 360 ms RMS/峰值校准、最近根音规则、1.5 ms 起音和
  90 ms 释放，使用自然采样衰减，不加循环、失真或混响。MIDI 0–127 全覆盖。
- SDK 实际节拍器使用 bank 128 / program 0 / key 33。只替换这个键为原创
  45 ms 衰减木质短音；圆滑起音、无方波及噪声分量。预备拍和正式拍使用同一键。
- 通过 `changeTrackVolume` 将原始轨道相对音量乘 0.15，主音量 0.8，节拍及
  预备拍音量均 0.9。恢复播放时关闭预备拍的 v91 行为继续保留。
- SoundFont 以应用资产 `sonivox.sf2` 覆盖固定 Android SDK 的同名默认资产，
  继续使用其原生载入器。132 个原预设仍在；钢弦、电吉他、其他乐器和其他鼓键
  保留原采样及映射，GP 文件原乐器身份不改变。

旧 PCM 播放器没有恢复。本轮没有改动谱面、曲包、和弦、光标、变速或循环逻辑，
没有新增播放器、计时器、调度器或音色选择界面。

## 来源与复现

nylon 来自 FreePats Spanish classical guitar 2019-06-18，Roberto，CC0-1.0；
逐 PCM 哈希与源提交见原 `guitar-nylon/manifest.json`。Sonivox 后备库来自固定
alphaTab 1.8.4 AAR，Apache-2.0；原版权信息、许可及修改说明保留。原创节拍短音
以 CC0-1.0 提供。详细来源见 [资产说明](../app/src/main/assets/third-party/practice-soundfont.md)。

`scripts/build-practice-soundfont.py <alphaTab-1.8.4.aar> --check` 使用 Python 标准库
逐字节复现。最终 SF2 为 4,629,142 字节，SHA-256：
`02ab9f358d1d79906e07ba8eb1d08993addfa3f23a9aaebea51e4589379a2bf8`。

## 验证与交付边界

独立结构核对确认原 132 个预设、全部原始采样字节和其他乐器区域保留；旧表中
只改变 nylon 预设引用及标准鼓组的 key 33 区域。新增 22 份 nylon 和 1 份节拍采样。
`AlphaToneTest` 使用实际 Android SDK 合成器及应用打包资产检查全部采样根音、
上下移调、其他吉他预设、六弦 FFF 和弦/扫弦与节拍混音。该检查验证数值信号，
不能证明手机扬声器上的听感。

最终混音在六弦 FFF 和弦开头 45 ms 内，节拍独立信号的 RMS 高 7.59 dB；
节拍峰值 0.333、和弦峰值 0.123、同时混音及扫弦峰值约 0.332（满幅为 1）。
节拍在 60 ms 后归于静音，保留明显峰值余量。2 项音色检查及 7 项现有迁移回归通过。

最终构建、CI、签名及 APK 资产核对证据保存在本地 `output/alphaTab-v92/`。
当前未连接 adb 真机；覆盖安装、实际音色、节拍辨识和连续播放由用户真机验收。

接口依据：[独立轨道音量](https://www.alphatab.net/docs/reference/api/changetrackvolume)、
[节拍器音量](https://www.alphatab.net/docs/reference/api/metronomevolume)、
[预备拍音量](https://www.alphatab.net/docs/reference/api/countinvolume)，
并以固定 1.8.4 Android AAR 源码核实载入资产名称与 key 33 映射。
