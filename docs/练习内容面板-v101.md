# v101 练习内容面板

基于 `codex/studio-dark-v100` / `becce74`，在独立分支 `codex/content-panel-v101` 实施原重构方案及用户的第 6 节视觉补丁。版本为 `101 / 4.3.3-local53-content`。

## 最终展示规则

- 一级 Tab 与二级来源栏固定在卡片滚动区外，曲包用稳定 `packageId` 聚合；胶囊只显示曲名。管理入口固定在来源栏尾部，完整无障碍名称为「管理导入曲包」，不占用「完成」所在标题栏。
- 来源筛选只修改浏览状态。和弦页没有该来源内容时高亮基础训练，保留共享来源；返回歌曲页、关闭重开面板或 Activity 恢复时沿用来源。曲库加载完成前不清空恢复值；来源删除或停用后才回退。
- 曲包只有一个子分组时隐藏标题和数量，直接显示网格；两个及以上分组保留轻量标题和数量。基础训练始终显示小节标题，取消外层套卡片。
- `local.mozart` 明确归入基础训练的「单音」，与 C 大调小句合为四张卡片，不生成独立来源。简单和弦节奏与综合片段展示合并为「节奏与综合」。
- 内置标题按完整白名单拆分；技巧标签、Block 编号和和弦品位提示保留。歌曲卡片剥离重复曲名，无标签时左对齐、垂直居中。未知格式保留完整信息。
- 选中卡片使用主题主色 10% 叠加底色、1.5dp 主色边框和加粗标题，并提供选中语义。手机常规字体和弦三列、短句两列，宽屏最多五列和弦，大字体降列；和弦标题测量后最低 12sp，仍过长时换行保留信息。音阶指型沿用原卡片入口。

K265 第二张在当前原始曲包中名为「莫扎特 K265 · 2 发展」，按本次用户白名单只将其展示改为「2 变奏」；原始名称、ID、谱面和音乐内容保持。

`ContentPresentation.kt` 只派生来源、分组和文本，`PracticeApp` 保存共享来源，`PracticeControls` 控制吸顶与滚动，`ContentCards` 接受可选的展示文本。没有修改 Repository、曲包、音乐数据、播放引擎、曲谱编译或设置迁移。
