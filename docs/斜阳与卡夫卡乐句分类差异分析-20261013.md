# 《斜阳》与《卡夫卡》乐句分类差异分析

日期：2026-10-13。依据两段完整对话、当前源码与两份原始 GP 的只读检查。

本报告记录v68／v70当时的分类与实现。用户随后要求精简《卡夫卡》，后续结果见[核心练习精简v71](卡夫卡核心练习精简-v71.md)。

## 结论

两次采用了不同的分类单位、声部收录范围和界面分组方式。源谱本身也有长度与编配差异，因此结果不同有合理部分；但当前的“5类”和“13类”不是同一口径，不能直接比较为歌曲各有多少种不同乐句。

《斜阳》采用经过讨论的五个练习素材家族，并各选一个声部作为核心练习；《卡夫卡》直接采用源谱 A–M 字母标记作为分类，并收录三个吉他声部的完整素材。“不要拆得过细、保留整段”固定了练习长度原则，没有固定分类的依据和展示层级。

## 两段对话的实际差别

- `统计《斜阳》乐句类型`，thread ID `01a1301d-a5d2-7dc3-86a1-d4ab484a7a6e`：先提出9类21个小片段；用户要求完整 solo/riff 后，修订为5类素材、6次完整段落出现；用户随后明确“按5类分，整合进app里”。完成后，助手才生成用于下一首歌的流程提示词。
- `整合吉他谱并交付签名 APK`，thread ID `01a13294-71fc-77c2-aa6e-c21cbfcaa509`：用户使用上述流程提示词，其中明确“分类数量由新歌决定，不机械套用《斜阳》的5类”。助手读取源谱后自行决定“以源谱的 A–M 正式段落作为13类，分别保留伴奏、主音和填句声部”。该对话没有另行统一音乐功能与字母标记的分类口径。

因此，《卡夫卡》的提示词是《斜阳》完成后提炼的模板；《斜阳》实际实施还受到多轮修正和明确五类指令的约束，两次有效上下文并不相同。

## 分类差异如何进入代码

`scripts/import-shayou.py` 的 `PARTS` 手工指定五条练习的名称、范围和声部。`scripts/import-kafka.py` 从 GP 的 `Section/Letter` 获取完整段落边界，并据字母填写“X类”。后者的重复检查比较声部、速度、拍号、摇摆、事件与奏法；没有进一步把不同字母按音乐功能或练习素材家族归类。

例如，《卡夫卡》A段G1与B段G1完全相同，D段G1与G段G1完全相同，但仍保留A/B、D/G的不同字母分组，因为其他声部内容可以不同。这说明字母标记描述整曲结构与编配位置，不能直接当作彼此不同的伴奏类型。

界面在 `ui/PracticeApp.kt` 中按 `Phrases.all.groupBy { it.use }` 显示分组。两首歌的 `use` 字段填写方式不同，直接造成一个歌曲分组与十三个段落分组的视觉差异。现有 `Phrase` 使用自由文本表达这些信息，没有分别规定歌曲、音乐功能、素材家族、源谱标记、声部与变体的层级。

因此，这次差别可以追溯到明确的导入和元数据决策；不需要用模型随机性解释已经有证据的实现差异。

## 《斜阳》尾奏的具体遗漏

原[完整乐句分析](C:/Users/b3322/Documents/ChatGPT/吉他谱子/work/斜阳乐句分析-20261012/乐句分类.md)明确写出：间奏与尾奏属于同一素材家族，但尾奏包含独立结束，不能称为整段完全相同。尾奏为第39小节末弱起＋40–47小节；主音40–45复用10–15，46–47由节奏轨分解与延音收束。

本次直接读取原 GP 确认：46、47小节主音轨无音符，节奏轨分别有14、9个记谱音头。当前五条 `SHA-*` 练习未包含40–47小节，也没有尾奏变体；[v68记录](斜阳完整乐句-v68.md)明确说明不另设尾奏入口。

这使当前《斜阳》成为五条核心练习，而非覆盖全曲所有完整段落的素材集。要求“五类”并不必然要求“五条”：按后来提示词的变体规则，尾奏可以仍归 riff 类，同时作为第六条完整变体保留。这一处执行口径需要统一。

## 统一口径的建议

采用“歌曲 → 音乐功能／素材家族 → 声部 → 完整变体”的展示层级；GP字母、小节范围和原轨名称保留为来源信息。源谱有功能名称时优先沿用；只有字母时不未经分析就认定为新的音乐类型，功能无法确认则暂保留原标记并说明。

分别报告四个数字：按时间顺序的完整段落出现数、素材家族数、完整声部练习数、独立变体数。完整相同的声部素材复用，有不同结尾或明显变化则保留完整变体；不同声部增加练习条目，不自动增加顶层类型。声部覆盖范围应明确说明。

可补进后续提示词的条款：

> 分类先区分音乐功能、素材家族和源谱段落标记，不直接把GP的A/B/C字母当作不同乐句类型。顶层按歌曲和音乐功能／素材家族统一展示，声部及完整变体放在类内。分别统计全曲段落出现数、素材家族数和完整声部练习数。相同内容复用，独立结尾保留同类完整变体；不要为了维持分类数量省略不同的完整收尾。明确所收录的吉他声部范围。
