## 本轮收录与和弦

先补齐四个指法，再接入 S01《嘘月》10–11 小节的低音与高音分解。原八个开放和弦保留，总计十二个和弦可逐弦检查。

| 和弦／指法 | 6→1 弦品 | 实际音高（低→高） | 和弦正确性 |
| --- | --- | --- | --- |
| Gsus2 | `3 X 0 2 X X` | G2、D3、A3 | 根音、五音、挂留二音；没有三音 |
| Asus4(no5) | `X 0 0 2 X X` | A2、D3、A3 | 根音、挂留四音；明确省略五音 E |
| Bm7(no5) | `X 2 0 2 X X` | B2、D3、A3 | 根音、小三音、小七音；明确省略五音 F♯ |
| D/F♯ | `2 X 0 2 X X` | F♯2、D3、A3 | D 大三和弦第一转位，低音为 F♯ |

`no5` 表示省略五音。不是把普通 A、Bm 的名称直接贴到缺音的指法上。挂留和弦的三音允许缺席，小七音与挂留音有独立标签，不再一律显示为五音。X 弦不显示可弹位置，也不进入检查或音频。为本段固定最小指法，不额外加入未弹的高音弦或通用和弦库。

声音延响至同弦再次拨奏、换指法或句尾，不在每个八分音符后截短；记谱时值保持八分音符，不伪造延音连线。每次循环从绝对时间换算采样帧，句尾不越入下一轮。

## 素材记录与改编

使用桌面三轨版本 `嘘月.gp` 的 Rhythm Guitar。印刷 10–11 小节对应 GP master 数组索引 10–11，前面有未编号弱起。指定节奏吉他 PDF 只用于核对编号和弦品位置，桌面原文件未修改。源文件路径、大小、SHA-256 与提取事件见 [source-S01.json](../output/source-S01.json)。

逐音序列为 `G2 D3 A3 D3 / A2 D3 A3 D3 / B2 D3 A3 D3 / F♯2 D3 A3 D3`，所有音位与标准调弦计算出的 MIDI 一致。GP 的 Triplet16th 标记不改变这些八分音符。

按本轮要求，不做出版社、原录音或原曲版本真实性调查。作为「伴奏改编练习」交付：补注符合实际组成音的和弦名称，延响在换指法和两小节句尾收音，便于循环。此命名是本轮音乐解释，不宣称源谱已明确标出同名和弦。

延期清单：S03《春泥棒》变调夹 3 品；S04《花に亡霊》变调夹 2 品；S05《斜阳》变调夹 3 品；S02 替补和 S06 降半音素材。单音旋律／riff 不属于本次和弦实施。本轮无夹和弦部分独立交付，不称原四条完整方案全部完成。
