# v65 平板窗口、标准节奏六线谱与空弦布局

日期：2026-10-12（Asia/Shanghai）。用户按三张截图要求修复平板黑边、将品位与节奏做成标准六线谱、缩小纯空弦练习的显示区域。本轮工作目录为 `guitar-practice`，基线 `e67ee5d`，施工分支 `codex/tablet-standard-tab-v65`。

## 实现

- `MainActivity.kt` / `PracticeApp.kt`：大屏根据 `maximumWindowMetrics` 的较短边及密度识别，不能用已经被 Letterbox 缩窄的应用配置判断是否为平板。大屏与多窗口采用 `SCREEN_ORIENTATION_UNSPECIFIED`，跟随系统和窗口；手机继续指板竖屏 / TAB sensor landscape。方向赋值仅在变化时执行。Manifest 明确允许调整窗口尺寸并处理最小屏幕尺寸变化。未修改设备旋转、分辨率、密度或系统适配设置。
- `Tablature.kt` / `TabNotation.kt`：移除独立节奏音符头，数字本身作为 TAB 音符头；符干从最低有效弦的数字下方延伸至六弦下的共同符梁。八分一条、十六分两条符梁；二分音符双符干、全音符无符干；附点、休止、三连音括号、延音、扫弦和连奏继续读取原事件。休止置于六线谱内。小节密度超过窗口时可水平浏览，谱行仍可垂直浏览。没有改变编排、时值、音频起音或播放时钟。
- `Diagrams.kt` / `PracticeApp.kt`：完整路线全为 0 品时使用紧凑六弦音位条，标出相关弦、音名与 0 品，保留当前 / 下一状态、点击试听与撤提示。纯空弦主卡按内容高度显示，图示区域不再占满剩余页面。混合空弦和按品时，空弦固定在琴枕外的窄区域；绘图与点选采用同一位置公式。是否使用空弦布局从完整路线决定，休止或死音不会逐音改变卡片尺寸。

窗口策略参考 [Android 设备兼容模式](https://developer.android.com/guide/practices/device-compatibility-mode)。节奏 TAB 的二分音符双符干参考 [LilyPond 完整六线谱说明](https://lilypond.org/doc/v2.24/Documentation/notation/common-notation-for-fretted-strings.html)。
