# V3.1 架构与交付整改补充

2026-10-19 用户追加的五项要求优先于原规范中相冲突的数据条件和缺失处理规则；已完成的 P0–P4 架构及 UI 保留，最终交付版本递增为 1.1.0 / 105。

1. 内置四模块、迁移的 Music/Chords/SevenBlocks/Kernel 和当前曲包必须填入明确教学数据：每个按弦/触弦谱音的 1–4 指、六弦 O/X、横按、和弦生效区间。修正数据后正常加载，不以缺失文案或缺失报告代替实施。
2. Fmaj7、Bm7(no5)、Gsus2 保留真实名称、性质与构成音，分别作为 F、Bm、G 的新手友好替代挂在同一切换入口。歌曲原配版与实际改音的简化版也在同一版本槽切换。
3. 所有相邻段落都能练衔接：按实际小节/拍点截取前段末小节和后段首小节；边界延音截断、入界音重新触发。弱起、变拍号和延音均不禁用入口。和弦音靶心可选手动参照，缺少自动事件时有教材参照。
4. P5 必须有完整代码与可操作的数据：100%→30%→0% 仅改变领奏，伴奏保持；倒序接龙逐步扩展正向循环范围。内置 A 小调问答及 J-Rock 各有独立领奏/伴奏轨和四个小节边界。
5. 音高保留整数 MIDI，调号用静态音名表。4& 空弦换形作为指定练习的静态动作提示；保留来源谱中的推弦等真实技巧，不引入运行时和声冲突计算。

具体实现、审计与已验证边界见 [实施记录](教学体系-V3.1-实施记录.md)。原规范文档原样保留以便追溯。
