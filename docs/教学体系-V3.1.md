# 吉他新手教学体系 V3.1｜教学体系与功能整改统一实施版

> **定位**：供执行 Agent 直接使用的**唯一生效**教学设计、数据重构、功能整改、迁移和验收总规范。  
> **依据**：V3.0 整合实施版 +《吉他练习 App 整改清单（精简版，2026-10-19）》，继承已确认的教学设计与整改决策。  
> **最高原则**：**新教学体系决定目标架构；旧数据向新体系迁移，而不是新体系向旧代码妥协。**
> **文档优先级**：本文件覆盖上述两份执行稿；原稿留作来源参考，不再并行安排施工。

## 0. 执行总则（优先级最高）

1. **教学正确性优先**。目标是能教会新手弹、听、理解和应用，而不是维持 `Music.kt` 现状。旧枚举、类型、字段、文件组织、UI 组件允许重构；迁移复杂度由代码及外部 Agent 承担。
2. **保留内容与能力，不保留错误设计**。正确的旧和弦、音阶、乐句、节拍、音频播放与用户已有曲包应转换进入新数据模型；纠正错误音名、音级、手指与分类；禁止以“旧格式不支持”为理由删减新方案要求。
3. **随选随练**。四个并列分类：基础启蒙、和弦教学、音阶教学、综合应用。进入 App 后选内容即可练，手动改 BPM、循环与提示。没有课程锁、评分、麦克风听音判错、计数达标、强制 15 分钟流程或用户档案。
4. **外部制包、内部执行**。曲谱/乐句和教学元数据由执行 Agent 在 App 外制作、校验和打包；App 读取标准曲包、显示和播放。**不恢复 GP 导入的复杂交互**，不在运行时对任意曲谱做不可靠的和弦识别、配指和改编。允许对已知、明确的结构做确定性计算（例如由已校验的弦品和调弦算音高）。
5. **兼容采取迁移/适配，而非双系统长期并存**。原有练习及曲包导入新结构，保留可追踪的旧 ID 映射；不为了兼容长期维护两份相互冲突的音乐语义。出现不能可靠恢复的教学信息时，标记“未提供”，保留可演奏内容；外部 Agent 可补完并重新验收，不得运行时猜测。
6. **移动端简单清晰**。用户只看到必要的练习、指法、音级和播放操作；数据结构可以专业，但不要把高级编辑器、迁移选项或技术字段暴露给用户。保持节拍器与合成乐器音量独立；声音、指板高亮和实际节拍须对齐。

## 1. 教学路线与功能边界

| 并列模块 | 必备教学内容 | 练习方式 |
| --- | --- | --- |
| **基础启蒙** | 单弦交替拨弦与双手同步；爬格子专用保留指；单八度音乐化模进 | 单击短句即播放，可循环和调速 |
| **和弦教学** | 构成音、可弹琴弦、左手指法/横按、常见哑音原因；双和弦转换；基础伴奏 | 单和弦自检、和弦对循环、节奏短句 |
| **音阶教学** | 单八度、大小调五声、七声补全、开放把位、封闭可移动指型、根音定位 | 选调式与练习，切换适用的指板提示模式 |
| **综合应用** | 和弦与音阶结合、加花、低音走向、Power Chord、掌闷音、J-Rock Riff | 短句/标准曲包直接跟弹 |

教学顺序是**推荐的理解路线，而不是必须完成的关卡**。同一素材可从不同分类进入，尽量复用播放内核。

## 2. 音乐语义统一规范

### 2.1 调式、音级与音高

- 每个调式明确保存主音、调式类别、音程集合、理论拼写和可供展示的音级：
  - 自然大调：`1 2 3 4 5 6 7`，相对主音半音偏移 `0 2 4 5 7 9 11`。
  - 自然小调：`1 2 ♭3 4 5 ♭6 ♭7`，相对主音半音偏移 `0 2 3 5 7 8 10`。
  - 大调五声：`1 2 3 5 6`；小调五声：`1 ♭3 4 5 ♭7`。
- **调内音级**与**当前和弦自身音程**分开。例如 G 和弦在 C 大调中的调内音级是 `5 7 2`，但相对 G 和弦是 `1 3 5`。
- 不用关系大调 `6/La` 充当小调自身的 `1`；在显示首调唱名时清晰标出所选参照，避免两套体系混写。
- 音符数据区分**实际音高**（MIDI/音分或等价内部结构）、**音级/音程关系**、**书写音名**。考虑调号正确拼写 `F♯`、`C♯` 等，不能仅用 12 个升号音名统一替代所有理论写法。
- 支持标准调弦、曲包指定调弦、变调夹及其对发声音高的影响。**按法名称（shape）与实际和弦名称（sounding）须分别表达**，和弦根音/构成音/提示应基于与当前显示语义一致的实际音高，不得在 Capo 2 时仍将实音 D 当作 C 的根音。

### 2.2 和弦/指法数据

每个可练习的和弦配法（voicing）应能够表达：

- 和弦标识、按法名称与实音名称；和弦根音、音程构成、可选和声功能/教学说明。
- 6 根弦的**不弹 X／空弦 O／按品**；手指编号 `1–4`；横按的手指、起止弦、品位；可演奏音高与最低音（含转位）。横按要有明确结构，不能靠重复手指编号无条件推断。
- 一个和弦可以有多个不同配法：开放、简化、免横按、横按、不同转位。**配法难度是提示属性，不等于和弦质量相同**。
- 推荐落指和手指移动路线与**具体两个配法**绑定；保留指须同时满足“相同琴弦 + 相同品位 + 同一手指”，不可只凭名称或共享音名推断。
- 缺少实际指法时可展示已知谱面和音符，标明“未提供指法”；不自动编造保留指/横按建议。

**和弦名称不可混称：** `Fmaj7 ≠ F`、`Gsus2 ≠ G`、`Bm7(no5) ≠ Bm`。允许注明“在某些歌曲中可替代”并给出差异，但不称为完全等价的低级版。`Bm7(no5)` 是 B–D–A，缺 F♯、含小七音 A；`Asus4(no5)` 不等同 A 大三和弦。

### 2.3 乐句与曲包数据

- 曲包包含稳定的 `packId/version`、段落/版本卡片、轨道/调弦/变调夹、和弦及其生效时段、事件与时值、演奏技巧（滑音、击勾弦、闷音、重音、休止等）、可选教学注释和指法。
- 时间语义精确到节拍/小节位置，确保声音、节拍器、播放指针、指板高亮一致；不同轨道无需伪装为单轨。
- 课程提示数据与演奏数据分离：缺少提示不妨碍播放；提示存在时必须对应真实事件/配法。
- 曲包版本升级须有明确的转换器与校验器；避免对历史数据静默改义。曲包内的和弦名与实际发声音高有冲突时报告并阻断该错误标注进入正式教学。

## 3. 基础启蒙：3 组小练习

| 练习 | 具体内容 | 教学要点 |
| --- | --- | --- |
| **FB-1 单弦拨弦与同步** | 在 3 弦等单弦上用空弦与 1–4 品，四分和八分、下上交替拨弦 | 右手时点、左手按弦准确、放松 |
| **FB-2 爬格子与保留指** | 4/3 弦或其他邻弦，半音阶 `1–2–3–4` 上行与反向练习 | **仅在此专项**练习上行暂不抬先前的手指；不把“不抬指”推广至实际乐曲及换弦的全部场景，避免僵硬 |
| **FB-3 单八度音乐化模进** | C 大调单八度，三音一组 `1-2-3 / 2-3-4 / 3-4-5`、简单折返和问答句 | 在正确节拍和可听旋律中学习，而非只爬点阵 |

保留现有 SevenBlocks 及 KernelPhrases 的正确内容，统一迁移至新曲包/乐句结构，作为可选进阶或关联练习，**不强制先完成 FB 才能使用**。

## 4. 和弦教学：单和弦与组合

### 4.1 单和弦卡片最小信息

- 名称、构成音（如 C：`C E G / 1 3 5`；Fmaj7：`F A C E / 1 3 5 7`；Gsus2：`G A D / 1 2 5`；Bm7(no5)：`B D A / 1 ♭3 ♭7`）。
- O/X、起始拨弦位置、每根弦真实音名、手指编号/横按区段；一键试听与逐弦自查说明（**提示**，不是麦克风检测）。
- 简短解释“它听起来/在进行里起什么作用”。例如 G→C 属到主的归属感；C→Am 的色彩变化；不用写成过长百科。
- 同一名称下可选不同配法，标注适用场景；不把不同和弦性质的替代方案标为同一和弦 Lv.1/2/3。

### 4.2 双和弦切换示例（以配法为单位而非仅以名字为单位）

| 组合 | 可教的动作 | 注意 |
| --- | --- | --- |
| `Am ↔ C` | 2 弦 1 品食指与 4 弦 2 品中指保留；无名指在 3 弦 2 品与 5 弦 3 品移动 | 标准共同指示例 |
| `C ↔ Fmaj7`（`xx3210` 配法） | 2 弦 1 品食指保留，中指由 4 弦 2 品到 3 弦 2 品；无名指由 5 弦 3 品到 4 弦 3 品 | Fmaj7 为独立和弦，不是假称“小 F”完全等价 |
| `E ↔ Am` | 相同指型整体向细弦侧移动一组弦 | 配对指法固定后再显示路线 |
| `Em ↔ Am` | 按所用配法重新组织手指，不预设共有保留指 | 可换其他指法，但必须同步更新说明 |
| `C ↔ G`、`Am ↔ D` | 目标手型预备；低音或首发声音先到位作为**可选**提示 | 不强制“所有和弦低音优先落指” |
| `G → D/F♯ → Em` | 6 弦低音 `G(3) → F♯(2) → E(0)` 下行 | 结合真实时值与低音线，不单纯机械换形 |

“4 & 空弦换和弦”仅作指定扫弦曲目里的**可选技巧**，需要校验空弦与当时和声是否合适；不是通用的换弦法则。

## 5. 音阶教学：单八度 → 五声骨架 → 完整音阶 → 可移动把位

### 5.1 路径与术语

- 优先用**起止主音明确、手型跨度可控**的单八度微单元；不规定必须恰好 3 根弦，4 根弦也可以。
- 对同一调式，先认主音与基本旋律，再观察五声骨架；随后补齐七声音阶的其他音。五声不是“乱弹一定和谐”，落音仍须结合和弦与节奏。
- 开放把位与可移动封闭指型是两种不同教学对象：**绝不能直接把包含空弦的开放指型整体平移**。需要预置经过核验的非空弦封闭指型（含手指建议），再作等距转调示范。
- 3 弦 G 与 2 弦 B 为大三度调弦；跨这组弦移植**相同音程几何关系**时作一品补偿，不是所有练习无条件“右移一品”。

### 5.2 已校验的开放把位单八度/五声示例（标准调弦 EADGBE、无变调夹）

> 记法：`弦号:品位(音名)`；箭头仅表示**本表的音符顺序**，UI 的“切换 Box 箭头”另按交互规范处理。

| 练习 | 弦品路线 | 重点 |
| --- | --- | --- |
| **C 大调单八度 C3→C4** | `5:3(C) → 4:0(D),2(E),3(F) → 3:0(G),2(A) → 2:0(B),1(C)` | 8 音；原 `Patterns.s1` 可迁移 |
| **C 大调五声** | 在上述音阶中仅取 `C D E G A C` 的顺序路径 | `1 2 3 5 6`；补 F、B 成七声 |
| **A 自然小调五声** | `A C D E G A`；另做开放把位单八度与第 5 品封闭把位练习 | `1 ♭3 4 5 ♭7`；加 B、F 成自然小调 |
| **G 大调低音区单八度 G2→G3** | `6:3(G) → 5:0(A),2(B),3(C) → 4:0(D),2(E),4(F♯) → 3:0(G)` | 7 级导音为 F♯ |
| **G 大调高音五声 G3→G4** | `3:0(G),2(A) → 2:0(B),3(D) → 1:0(E),3(G)` | 便于 G 和弦旋律加花 |
| **E 自然小调单八度 E2→E3** | `6:0(E),2(F♯),3(G) → 5:0(A),2(B),3(C) → 4:0(D),2(E)` | 五声骨架 `E G A B D` |
| **D 大调单八度 D3→D4** | `4:0(D),2(E),4(F♯) → 3:0(G),2(A) → 2:0(B),2(C♯),3(D)` | F♯、C♯ 两个升号 |
| **B 小调五声 B2→B3** | `5:2(B) → 4:0(D),2(E),4(F♯) → 3:2(A) → 2:0(B)` | 清理 V2.1 中残留的错误草稿 |

- `C/Am`：先认识无升降号体系；`G/Em`：在 C 音列基础上改变 F→F♯；`D/Bm`：再改变 C→C♯。这是**帮助理解调号的比较方法**，不要误解成随便在旧指法上改一个点就保证手型正确。
- A 小调第 5 品 Box1、B 小调第 7 品等封闭指型应另有一份确定的数据/指法验证；G 小调对应可向第 3 品平移，但需要验证完整范围、根音位置与左手跨度。
- 支持从任意主音按音程生成理论音阶，但首批教学内容重点安排 `C/Am`、`G/Em`、`D/Bm`，**无需预制 12 套近乎重复的启蒙课程**。新数据结构不可被这三组限制。

### 5.3 指板提示：5 个手动、互斥的视图

| 模式 | 显示 | 前置条件 |
| --- | --- | --- |
| `FULL` | 当前练习所用音阶/指型全部音点、音名或音级、已提供的建议指法 | 有音阶/指型数据 |
| `PENTATONIC` | 当前调式的五声骨架突出，其他调内音弱化 | 知道调式与五声集合 |
| `CHORD_TONES` | 在当前指板范围内突出**所选/当前事件的和弦实际构成音** | 明确的和弦对象、配法或和弦时段 |
| `ROOTS` | 当前所选**调式主音**；在和弦练习中可明确切换为“和弦根音” | UI 必须标注根音所指对象 |
| `HIDDEN` | 不显示提示音点 | 无额外条件 |

这些是**互斥选择的视图，不是同时启用的 5 个开关**；只显示当前练习适用选项。`CHORD_TONES` 不得假装推断“不明确的当前和弦”；若只知道曲目没有和弦事件，可先选择具体和弦，也可显示该模式不可用并说明原因。和弦音可通过已确认的和弦结构作确定性计算，**不能依赖某一旧曲包缺元数据就删掉此能力**。

UI 箭头：**只用于切换 Box/把位**；单音进行靠事件高亮，滑音用专门 slide 连线/符号，不用通用箭头逐音跳动。

## 6. 综合应用：从“会按”到“会用”

### 6.1 和弦音靶心和加花

| 和弦 | 和弦构成音 | 相对和弦的音程 | 相对 C 大调 | 相对 A 自然小调 |
| --- | --- | --- | --- | --- |
| C | C E G | `1 3 5` | `1 3 5` | `♭3 5 ♭7` |
| Am | A C E | `1 ♭3 5` | `6 1 3` | `1 ♭3 5` |
| Fmaj7 | F A C E | `1 3 5 7` | `4 6 1 3` | `♭6 1 ♭3 5` |
| G | G B D | `1 3 5` | `5 7 2` | `♭7 2 4` |
| Gsus2 | G A D | `1 2 5` | `5 6 2` | `♭7 1 4` |
| A5 | A E（可加高八度 A） | `1 5` | `6 3` | `1 5` |

- **C → Cadd9 → C**：标准 C `x32010`，第 3 拍小指补按 2 弦 3 品 D，产生 `x32030`；第 4 拍回到 2 弦 1 品 C。说明 D 是相对 C 的 9 音，既能听到色彩变化，也能理解不必换掉整个和弦。
- **和弦功能小示范**：`G → C`（属→主、回归感）、`C → Am`（大/小三和弦色彩变化）、`G → D/F♯ → Em`（低音级进下行）。用 2–4 小节示范，不增加强制课程流程。

### 6.2 G/Em、D/Bm 家族与变调夹

- **G/Em**：`G、Em、C、D、D/F♯、Am`，以及按实际效果适用时的 Gsus2；示例 `G → D/F♯ → Em → C`。
- **D/Bm**：`D、A、G、Em`，以及按场景适用的 `Bm`、`Bm7(no5)`、`Asus4(no5)`；示例 `D → A → Bm → G`，提供 Bm7(no5) 作为**和声色彩不同的可选替代**而不是完全同物。
- **Capo 2 示例**：按法 `C – G – Am – Fmaj7` 的**实际响音和弦**为 `D – A – Bm – Gmaj7`，不是 `D – A – Bm – G`。展示“按法名 vs 实音名”，避免误导。

### 6.3 J-Rock 轻量专项

1. **Power Chords**：`E5/A5/G5/C5/D5` 双音与加八度三音版本；无三音意味着不直接指定大小调性质；可移动配法需明确根音弦与闷弦。
2. **掌闷音与八分驱动**：结合已有 `PM01/R01/R02` 语义做规范化练习，重音与开放击弦形成对比。
3. **小调五声旋律**：A 小调 5 品 Box1、顺逆行、跨弦拨弦、四音/三音序列、切分与短句；可用滑音连接相邻 Box。
4. **J-Rock Riff**：低音根音驱动与高音旋律呼应、八度音型平移、基础击勾弦；短句必须有可听的动机及结束音，不只堆技巧。

练习包长度以“短而完整、能听出音乐性”为原则，由外部 Agent 编写、分段、试听和校验；首批无需把所有高级技巧塞到同一首练习里。

## 7. 目标架构与旧数据迁移

### 7.1 目标数据层（可调整类名，不可削减表达能力）

建议按**调式/音高 → 指型/和弦配法 → 乐句事件 → 教学注释 → 标准曲包 → UI**分层。核心数据至少具有：

- `TuningContext`：各弦音高、变调夹、显示音名规则。
- `KeyContext/ScaleDefinition`：主音、调式、音程、音级与音名拼写。
- `FretPosition/Fingering/Barre`：弦品、手指、横按、可达性与真实发声音。
- `ChordDefinition/Voicing`：和弦质量、音程、具体配法、根音/转位、按法名/实音名。
- `Phrase/TimedEvent`：小节、节拍、音符/和弦/休止、拨弦方向及技巧、当前和弦区间。
- `LessonMetadata`：标签、教学重点、推荐路径、保留指和移动路线、听感功能、展示范围。
- `PracticePack`：卡片→段落→版本、素材与数据版本、课程关联，支持原有曲包内容进入统一模型。

名称可由执行 Agent 统一命名，不要求为了遵守此清单创建大量空类。**数据真值优先级：谱面与手工校验的配法/教学元数据 > 明确的确定性转换 > 缺失标记；不得猜测。**

### 7.2 迁移对象与规则

| 旧来源 | 新目标 | 处理办法 |
| --- | --- | --- |
| `Music.kt` 的 `Tonality`、`Patterns`、`Patterns.s1` | 可扩展调式、音程与音阶片段 | 转换为统一音高/音级定义，修正显示与调号；原 C/Am 结果可做回归基线 |
| `Chords.all` | 和弦定义与配法库 | 迁移弦品、X/O、手指，补和弦音与实音语义；新添 Fmaj7/Cadd9/Power Chords 等教学所需配法 |
| `SevenBlocks`、`KernelPhrases` | 标准乐句/技巧课程 | 保留正确事件、时值、技巧、音频和 ID 映射；有错误才修正并记录 |
| 旧曲包 | 新版标准曲包 | **离线转换并校验**，保持卡片/段落/版本、播放事件和节奏行为；缺失教学信息交给外部 Agent 补充 |
| 旧 `Hint` 与 UI 组件 | 新的互斥提示模式和指板渲染 | UI 改读统一模型；避免旧枚举限制新功能；保留正确交互与轻量样式 |

迁移验收最少包括：旧曲包可载入且卡片/版本与音符事件不丢、节奏/时值保持一致、实音计算正确、和弦 O/X/手指/横按显示正确、提示与发声同步、无法转换的字段有可定位报告。**允许修改旧 ID 或代码 API，但必须有映射和调用方迁移；不要求长期冻结旧接口。**

### 7.3 边界与反模式

- **不能**因为 `Music.kt` 只有 C/Am 就取消 G/D 或日后的其他调；新模型应从一开始表达任意主音/基本调式。
- **不能**因为旧和弦库缺 Fmaj7/Cadd9/Power Chord 就删除课程；应该补充教学配法、校验发声与指法。
- **不能**将未知手指、横按或和弦区间视作“推断正确”；运行时不猜。
- **不能**将旧 `FULL/ROOTS/HIDDEN` 视作不可修改的接口；应做兼容迁移。
- **不能**为迁移重新引入 GP 文件编辑器、繁复导入向导、答案闯关或本地个人档案。
- **不能**只做 UI 文案变更而让底层音级、调式与教学配法仍然存在互相矛盾的真值。

## 8. 练习体验与播放整改（吸收精简版全部 12 项）

> 本节只定义**使用行为、实现约束与验收**；和弦、横按、音阶、指板语义分别复用第 2、4、5、7 节的统一模型。整改优先级与实施依赖由第 9 节唯一管理，不沿用旧清单中重名的 P0–P3 编号。

### 8.1 谱面上下滚动后消失／显示错误（原清单 1）

- **现象**：谱面下滑再回到原位置，音符不显示或错位；点「展开指板」或切换页面可恢复，属于稳定复现缺陷。
- **处理**：定位滚动容器与谱面渲染的尺寸测量、可见区计算、状态恢复、重绘触发及视图生命周期；修复根因，不以强制切页/手动刷新掩盖。
- **验收**：多次上下滚动、切页返回、展开/收起指板、暂停与恢复播放，谱面完整且位置正确；无异常闪烁或明显卡顿。

### 8.2 统一 BPM 速度控制（原清单 2）

- **现象**：部分曲包（如《花に亡霊》）仍使用「原谱调节」或倍率文案，与应用其余 BPM 控件不统一。
- **处理**：界面以 **BPM 为主要调速语义**，明确当前有效 BPM、所依据的原谱 BPM 与必要的倍率换算；用户继续手动调速。对于谱中存在变速事件的内容，应保留原曲 tempo map，以用户速度控制规则统一缩放各速度事件，并在界面明确当前播放点/当前段的有效 BPM；不得将变速谱错误描述为整首恒定 BPM。
- **验收**：显示与实际拍点/乐器播放一致；切换段落与版本、暂停/继续、拖动定位和重新进入均按同一规则呈现，不出现控件数值与声音速度脱节。

### 8.3 节拍音量与音乐音量独立（原清单 3）

- **界面**：在现有播放控制内提供简洁「音量」入口，只有两条滑杆：**节拍音量 0–100%**、**音乐音量 0–100%**；均可归零静音，播放时即时生效，并全局保存，下次启动恢复。
- **音频职责**：节拍滑杆控制节拍器拍点及同类预备拍；音乐滑杆控制曲谱/乐器的**总音乐输出**。分别调节相应增益，不修改 Android 系统媒体音量；两者独立且无爆音、无无故中断。新音乐模型只提供时值/轨道等语义，不另建与播放引擎冲突的音量体系。
- **验收**：分别测试只听节拍、只听音乐、两个音量不同、全静音、播放中实时调整、重启记忆与设备音量键行为；节拍声和谱面播放始终同步。

### 8.4 和弦教学卡与指板箭头（原清单 4、5；不重复造轮子）

- **唯一数据来源**：第 2.2 节的和弦定义/具体配法和第 4 节的教学说明；歌曲内和弦显示还使用实际生效时段，不将「单个和弦的性质」冒充「其在当前曲段的和声功能」。
- **展示**：构成音、性质、常见用途、按法/实音名、O/X、实际声音名、手指编号、完整/局部横按、首发声弦；如曲包指定该段配法，以其为准。缺少指法则如实标记。
- **箭头**：沿用第 5.3 节：单音以音点/事件高亮表达，只有显著**换把位/切换 Box**才使用移动箭头；滑音单独使用 slide 连线/技巧符号，避免混用。
- **验收**：同一配法在和弦页/歌曲页保持一致，横按起止弦及品位正确；单音不出现误导性移动箭头。

### 8.5 相邻段落衔接循环（原清单 6）

- **操作**：相邻段落可选「衔接练习」，默认**上一段末 1 小节 + 下一段首 1 小节**，连续循环；若底层已有可靠 tick/拍点范围能力，可按经验证的曲包数据切为「尾 2 拍 + 头 2 拍」。
- **数据**：优先用曲包明确标记的推荐范围；未提供时只对边界明确、可验证的相邻段落构造一小节衔接。不要在弱起、跨小节延音、变拍号、版本不相接等情况猜错时值。
- **验收**：进出循环、播放指针、音频、节拍与和弦/指板高亮全部同步；不截断延音或跳错小节，无法安全构造时禁用该衔接入口并提示原因。

### 8.6 前瞻指板与动作提示（原清单 7）

- **展示**：当前事件使用清晰实心高亮；**下一个关键位置**可用低对比度预告标记。曲包提供可靠指法/注释时，提前提示横按准备、换把位、已校验的保留指、拨弦或扫弦方向；高密度段落仅留关键动作。
- **约束**：这是播放时间轴驱动的**静态教学提示渲染**，不是 App 实时推断用户弹得怎样；具体动作以第 2.2、2.3、7 节定义的数据为准。未知手指或动作时不自动补出。
- **验收**：预告时机恰当、不遮挡谱面；播放、暂停、拖动、循环、换版本和返回页面后状态不滞留或错位；不会向用户显示假的横按/保留指。

### 8.7 教学版本直接切换（原清单 8）

- **操作**：在当前曲段内可手动选择**原谱版／简化版／律动版**等外部已制作版本；实际提供哪些就显示哪些，普通曲段允许只有一个版本；不强制多选一次才能练。
- **数据**：沿用新 `PracticePack` 的卡片→段落→版本映射，同一段的不同版本有明确事件、时值、和弦、调弦/Capo 和速度信息；不在 App 内临时改编或猜和弦。
- **验收**：切换后谱面、播放范围、有效 BPM、和弦/指板提示与相应版本一致；已转换的单版本旧包仍可直接播放。

### 8.8 可选的针对性热身（原清单 9）

- **操作**：曲包可引用标准基础训练 ID，例如横按转换、跨弦拨弦、目标把位音阶。曲段页只增加轻量「练前热身」入口，用户主动点选进入，结束可直接返回当前曲段。
- **约束**：引用经过校验的现有/新练习；由外部 Agent 关联真实难点。没有关联时不显示入口；**绝不插入必经开练流程**、每日任务或达标机制。
- **验收**：歌曲仍可一键开练；热身与曲段互相定位正确，返回不丢当前版本和练习范围。

### 8.9 曲包教学字段（原清单 10；已统一到目标模型）

- 数据不另起炉灶：版本关联、推荐衔接范围、和弦配法/横按、关键动作、拨弦方向及练习引用统一落在第 2.3、7.1 节的 `PracticePack / Phrase / LessonMetadata` 中。
- **验收**：新包可正确显示可选教学信息；旧包经迁移后维持原有可演奏事件及版本关系，缺失的纯教学提示标记为未提供；无长期并存的「原曲包 UI 解析器 + 新曲包 UI 解析器」。

### 8.10 按需的两种播放能力（原清单 11、12）

**A. 渐隐领奏（仅用户主动启用）**

- 对曲包**确有独立领奏与伴奏轨道**的段落，可在循环间将领奏相对音量设为 `100% → 30% → 0%`；不改变和弦/音阶的练习进度，不做表现判断。
- 用户的「音乐总音量」始终是总输出控制，「节拍音量」始终独立；领奏比例只影响对应领奏轨，不压低其他伴奏。单轨或无法区分领奏的曲包**不显示/禁用**该模式。
- **验收**：跨遍循环无爆音；音乐总音量、节拍音量、领奏衰减相互独立；退出后恢复正常轨道比例。

**B. 倒序接龙（仅用户主动启用）**

- 适用于有明确连续小节/短句边界的 Solo 等段落：先循环末段，再逐步向前扩展练习范围；**只是播放范围操作**，不倒放音符、不重编事件、不做评分。
- **验收**：边界、循环及节拍准确；音高、实际曲序、和弦/指板提示正常；退出后回到用户原来选择的段落与循环范围。

### 10.2 稳定性、操作与声音
