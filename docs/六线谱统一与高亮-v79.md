# 六线谱统一与高亮 v79

2026-10-14，v79 / 4.0.0-local31。实现和本地验证针对当前 guitar-practice 工程。

## 结果

《嘘月 · 低音与高音分解》、P.M. 原创练习、音阶、和弦与曲包现在共用唯一六线谱路径：

`Sequence.performance → PerformancePlan.tabProjection → TabSystemLayout → PlanTablature`

旧素材在 LegacySequenceAdapter 转入既有音乐内核；外部曲包仍直接使用原 PerformancePlan。旧 Tablature/TabSystem Canvas 分支及两处未使用的旧宽度/分行计算已移除，保留的 TabNotation 只用于旧事件的书面节奏投影和来源验证。

## 播放高亮与坐标接口

| 文件 | 职责 |
| --- | --- |
| `ui/Tablature.kt` | 唯一入口，不按 runtimePlan 是否存在分流 |
| `ui/TabLayout.kt` | 小节、事件、音符、奏法范围、谱行尺寸及坐标；稳定事件/音符 ID |
| `ui/TabHighlight.kt` | Cursor/Phase 可见性、粉色当前音光条和 Mint 当前小节底色 |
| `ui/PlanTablature.kt` | 按布局绘制，复用旧谱行滚动动画，密集小节横向跟随 |
| `ui/TabSymbols.kt` | 从旧实现提取的休止符视觉组件，不包含旧坐标算法 |
| `practice/compile/PlanNotation.kt` | 按小节裁分谱面时保留事件身份，给跨小节片段匹配书面时值 |

高亮层接收布局输出，不计算另一套 X 坐标。Cursor 的 localTick 按原 Sequence 的 12/24 ticksPerQuarter 转成谱面 quarter，播放时间仍来自既有音频帧/Session/TempoMap；没有新增计时器、独立播放状态或节拍累计。

当前书面事件的光条与仍在延响的旧音分别处理，避免低音延响把所有旧起音都当成当前音。和弦同起音共用光条，死音/休止继续标明当前位置。暂停遵循既有播放器规则，返回当前小节起点；继续使用同一 Session，重来先进入原预备拍，变速按既有 invalidate/start 重置。结束、停止和错误清除演奏高亮。

旧版光条随 Cursor 直接更新，动画是谱行滚动；本轮保留这一语义，并使用新布局锚点增加密集小节的横向跟随。

## 记谱布局

- 品位数字以实际文本宽度留白，最后绘制不透明底垫，保护两位品、和弦及泛音标签。
- 品位数字直接作为 TAB 音头，去掉谱线上方额外的蓝色圆点音头；符干、连梁和分声部节奏带位于六弦下方。连梁在拍组、休止或不连续处断开。
- 连续 let ring/P.M. 只合并相邻且作用范围相同的指令；休止、例外和弦内部分弦的奏法不会被吞并。部分弦明确写弦号，多声部加声部标签。标记按实测文字宽度分配避让行。
- 《嘘月》原包 16 个八分音符/16 个延响音完整保留，显示为每小节一个延响范围；未改变原曲包字节或音频延响长度。
- 死音 x、休止、上下拨、扫弦方向、短促/重音/弱奏、滑音/击勾弦、泛音、弯音/颤音、摇摆、变拍和嵌套连音仍保留。旧素材已经折入声音强度/收音时间的显示提示通过 PlanEvent.notationMarks 保留，不二次改变音频增益或时长。
- 跨小节保留相同事件/音符 ID、延音连接及裁分后的书面时值，不制造新起音或重复的拨弦/重音指令。
- 手机与平板使用同一坐标体系；普通单声部谱行收紧留白，完整手机页面可同时显示品位与连梁。高密度/大字号保持字形尺寸并滚动完整谱行。

## 迁移与验证

迁移时旧 Canvas 暂时保留在 LegacyTablature；统一入口的布局、复杂曲包、手机与 38 个原始 Block 小节、播放器生命周期回归通过后，才移除旧实现。清理后继续运行针对性回归与发行检查。

自动化覆盖：

- TabLayoutTest：原 16 音/逐音身份、范围合并与例外、延响和当前起音分离、12/24 tick、跨小节时值、重音/短促/弱奏、隐藏/根音提示、续音不重复拨弦。
- UnifiedTabRenderTest：794×361 手机、1280×800 平板、640×360/1.4 倍字号；像素检查实际粉色光条；真实 Player 配合受控设备帧验证预备拍、暂停/继续、重来、跨小节、变速与结束；完整手机练习页及密集谱面双向跟随。
- 既有 RenderTest、SongRenderTest、SevenBlocksRenderTest、NotationTest 与针对性 SongKernelTest：原六弦位置/和弦/休止、所有 38 个来源小节、多声部、复合/不规则拍号、嵌套连音、奏法、泛音、弱起及声音兼容。

最终结果、APK 哈希和截图见下方交付记录。模拟渲染来自 Robolectric/native Canvas，不是真机截图；本机没有已连接的 Android 设备，未使用 Android Emulator。本轮未证明真机安装/启动、实际触控、音画同步或试听/实弹效果。
