# v66 平板大按钮与顶部两行

日期：2026-10-12（Asia/Shanghai）。本轮在 `guitar-practice` 的 v65 基线 `7f386ed` 上施工，分支 `codex/tablet-controls-v66`。参考上一对话「修复平板布局与六线谱显示」及其实际装机图，按用户要求放大按钮、整理顶部两行，并沿用熟悉的页面结构。

## 界面变化

- 当前窗口宽、高均达到 600dp 时采用平板操作尺寸；窗口变窄或变矮时沿用原有紧凑布局。常用文字按钮、模式切换、和弦上一／下一及设置选择项最小高度 64dp，主播放按钮 72dp，结束按钮至少 96dp 宽。按钮文字从 14sp 增至 18sp，播放图标相应放大；设置内的完成、速度加减、更多练法和整句入口同步适配。
- 第一行保留左侧「吉他练习」，右侧集中音阶／和弦和练习设置。第二行左侧显示练习视图或和弦学习／短句应用，和弦指板页保留上一／下一；右侧固定指板／六线谱。较大字体时左侧内容可以水平浏览，视图切换继续可见。
- 平板指板与 TAB 共用两行顶部和两行底部：速度、拍号与撤提示在上，听示范／开始跟练或暂停／继续、重来与结束在下。切换视图时操作位置保持一致。
- 左侧练习小提示、中央主卡、原指板／和弦图、卡片内播放状态及颜色保留。放大按钮后的平板高度判断单独适配，避免普通横屏落入手机精简规则而隐藏卡片状态。沿用 v65 的窗口方向策略、标准节奏 TAB 与紧凑空弦布局，以及现有内容、播放器和保存规则。

实现入口：`ui/PracticeApp.kt`、`ui/Style.kt`。最小点击区域的参考来源为 [Android 可访问性说明](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)；64dp / 72dp 是本轮为平板操作采用的尺寸。
