# V4 练琴界面补丁 v111

基线 `codex/unified-package-stage` / `ee6140a`；版本 `1.4.1 / 111`。

## 光标显示补偿

现有 BPM 弹窗加入全局光标同步设置：默认 0 ms、每步 10 ms、范围 −500～+500 ms、恢复默认值。正值延后，负值提前；修改即刻重画并写入现有 practice-settings SharedPreferences，不中断播放。

审计对象是 Maven Central 发布的 `net.alphatab:alphaTab:1.8.4` sources JAR 中的 `AlphaTabApiBase.kt`、`CursorHandler.kt`、`midi/MidiTickLookup.kt`、`synth/AlphaSynth.kt`、`synth/SynthConstants.kt`。采用公开 `customCursorHandler`、`tickCache.findBeat`、`renderer.boundsLookup` 和原生光标容器，未使用反射或私有 API。

只读复制生成 MIDI 的完整 tempo map，收到实际已播位置后，在显示帧间以单调时钟外推，减去真实毫秒偏移，再查询目标 beat/谱面坐标。小节背景和细光标一起补偿；换行使用目标行边界。延后跨循环时保留上一轮末尾，提前可进入下一轮；首次起点与最后终点钳制。暂停、停止、换曲、失败和释放时取消帧回调；预备拍沿用已有定点光标，正常暂停定位沿用引擎。

设置回调仅重画光标，不触发 seek、音频时间写入、MIDI 生成、曲谱事件修改、视图移动或重挂载。指板、节拍器与音乐事件继续使用实际听到的时间。SDK 默认自动滚谱和音符高亮仍按原播放位置，未改变相关业务。

## 整数 BPM 与实际范围

舞台和弹窗显示稳定的整数**起始目标 BPM**，以本练习首个原始速度为基准。内部每次直接计算 `目标 BPM / 首个原始 BPM`，统一缩放全部原始变速事件，不改曲包数据；进入变速段时保留速度比例，按钮中的目标值不跟随变速跳动。保留 −5/−1/+1/+5 与整数化滑块。旧倍率设置首次读取时迁移成整数目标；新值按练习保存为整数，避免反复用 Float 倍率累计误差。

1.8.4 实际 AlphaSynth 的倍率范围为 0.125～8.0。此次保留原 UI 的最高 2 倍，不扩大无关范围。最低值为 `max(20, ceil(原始 BPM × 0.125))`，最高为 `floor(原始 BPM × 2)`。例如原速 124/132/160 均可到 20 BPM；180 原速最低 23，240 原速最低 30。超过 160 BPM 的曲目会在弹窗明示该曲引擎下限，不展示无法实际播放的 20。

原先 App 自行设置的 25% 下限已从舞台和播放入口移除。新增测试直接运行依赖中的 AlphaSynth，验证倍率写入、真实时长/样本播放进度、变速段比例和 12.5% 钳制。

## 开关颜色与边界

循环/节拍关闭颜色与几何不变；开启使用各主题独立的实心颜色和高对比白色文字/图标：青绿 `#006D69`、陶土棕 `#88432C`、靛蓝主题青色 `#007F8D`。主题回归检查文字对比与开关背景差异，不增加任何标识。四按钮、稳定 AlphaTabView 挂载点、曲包协议/内容、依赖和包名保持原值。
