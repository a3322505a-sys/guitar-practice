## 本轮新增：尼龙弦音源

默认音源已切换为 [FreePats Spanish classical guitar](https://github.com/freepats/spanish-classical-guitar/tree/6f4eb1b092acc88f5448cea1a0001bd07b971af8)，2019-06-18 版，由 Roberto 在 2008 年录制，发布方采用 CC0 1.0。

- 22 个键中心，MIDI 40–77，覆盖现有练习的实际音域。PCM 16 位、单声道、22050 Hz，共 3,271,568 字节。
- 原始 PCM、完整许可及逐文件 SHA-256 保留于 `assets/soundfont-source/guitar-nylon/`。正式 SoundFont 对应的 LICENSE、README 和 manifest 由生产脚本复制到 `app/src/main/assets/third-party/nylon/`，随 release APK 分发；debug 另复用生产原料进行旧播放器对照。
- 衍生处理：保留实录拨弦起音、裁去前导采集静音但留 2 ms、25 Hz 高通、至多 8 秒、50 ms 素材末尾淡出；运行时 1.5 ms 起音和最多 90 ms 释音。没有加入失真或混响。
- 原电吉他素材保留作为旧音源对照；生产播放器只读取新音源，不存在第二个播放器或视图时钟。没有引入已核查的 GPL 钢弦素材。
- `scripts/prepare-nylon.py` 可按固定提交重新取得原素材；原 FLAC 存于本地 `.local/nylon-source`。准备脚本使用 task-local numpy/scipy/soundfile；构建 APK 不需执行准备脚本。
- 对照 WAV 用 App 的 Pcm 类产生相同事件、90 BPM 和无节拍声，再用 [pyloudnorm](https://github.com/csteinmetz1/pyloudnorm) 的 BS.1770 实现匹配 -22 LUFS。六段新旧响度差均小于 0.02 LU，详见 `output/audio-comparison/loudness-verification.json`。许可与数值检查不代表已确认主观听感。
