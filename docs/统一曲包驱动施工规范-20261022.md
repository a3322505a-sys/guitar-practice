## 一、不可更改的裁决

1. **Schema、曲包生成链不动。** 不修改 `manifest.schema.json`、`contracts/song-package/` 规范源、曲包生产脚本或既有 `.gpractice` 包装结构；不增加 `contentType`、`learningGoals` 等新字段。
2. **直接从现有数据推导。** 曲包的 `practices` 为唯一练习列表来源；有有效 `lesson` 或明确教学语义的 `teaching` 的曲包视为教学包，否则为普通曲包。`PracticeSpec.title/goal/order/lesson/teaching` 提供名称、教学目标与顺序；按 `order` 展示，没有专属教学页面。若某个包同时含教学和普通练习，仍作为一个曲包呈现其全部 `practices`。
3. **参考图并非每一处文字都要实现。** 谱面区域不显示伪标题 `AlphaTab 正式乐谱 / 演奏谱面`；直接展示真正的 AlphaTab 曲谱，尽可能占据可用高度。
4. **BPM 只有一个入口。** 顶栏右侧只读 BPM **删除**；只保留底部左一 BPM 按钮，不维护第二套 BPM 显示或同步状态。
5. **手机竖屏 360–412dp。** 顶栏左侧仅返回箭头，不显示“曲包库”字样；正文和底部按可用空间排布，谱面优先，底部四控件保持一排。
6. **主舞台绝不加教学组件。** 不得增加教学目标卡片、提示浮层、教学步骤条或独立课程工作台。若曲包含多个 `PracticeSpec`，只能在曲包库选练习，或点击顶栏中央「曲名 / 副标题」打开简易下拉列表切换；单练习无需切换入口。
7. **真正删除废弃 UI。** 不留旧词典页、音阶/和弦筛选胶囊排、分步跟练条（上一步 / 听当前 / 下一步）、试听/跟练（demo/follow）双模式 UI 状态分支及绑定它们的废弃 UI 测试。历史对比交给 Git，不保留僵尸代码和“回退页”。仅删除 UI 及失效 UI 测试，不借机删音乐内核实际在用的播放能力。
8. **AlphaTab 单一稳定宿主。** 顶栏下拉、指板折叠、进出曲包库、横竖屏变化均不得 detach/attach 或重建 `AlphaTabView`；不开发第二套播放器。
9. **不为 Android 8.0 专门兼容。** App 是自用工具，最低系统版本不是本轮验收要求；不为此主动改 Gradle 或添加依赖。

## 二、目标页面（固定）

```text
统一曲包库
  ├─ 曲包列表（教学 / 普通由现有元数据推导）
  └─ 点击曲包 → 选择 PracticeSpec（仅多练习需要）→ 进入同一个练琴舞台

练琴舞台
  ├─ 顶栏：返回箭头 | 曲名 / 副标题（多练习时可下拉） | 和弦 + 小节 / 拍号
  ├─ 横向全宽可折叠指板（位于乐谱上方，不是侧栏）
  ├─ AlphaTab 实际曲谱（无额外标题栏，主面积）
  ├─ 播放时间 / 进度条
  └─ 单排：BPM | 播放 / 暂停 | 循环 | 节拍
```

- 浅色青绿色视觉按最终参考图；不得回到深色复杂双工作台。
- 没有倍速按钮、试听/跟练模式选择、独立和弦指型、词典筛选、教学提示条。
- 主界面选择曲包/练习即可开始练琴；没有关卡、答题、强制教学顺序。
- 折叠指板后，释放的空间交给曲谱；播放高亮和跟随仍由现有 AlphaTab 能力承担。

## 三、施工顺序：三阶段，不跨阶段

### Phase 1｜曲包库与练习选择（合并原 Phase 1 + Phase 2）

**改造入口：** `ui/ContentPresentation.kt`、`ui/SongLibrary.kt`、`ui/PracticeApp.kt` 相关路由；按需读取现有 `SongRepository` 快照、`SongPackage.practices` 和 `PracticeSpec`，不改其序列化协议。

- 基于既有 `lesson / teaching / practices` 将曲包聚合为教学包或普通曲包，直接显示包名和已有练习列表。
- 教学信息仅用于**曲包库**的列表文字，不生成教学工作台。
- 选择子练习后沿用现有 `Phrase` / `Sequence` 加载与 AlphaTab 准备路径；不增加另一层课程引擎。
- 接好返回、选包、选练习的实际导航，不临时保留旧词典或旧课程页作为回退分支。

**阶段闸门：** `./gradlew :app:compileDebugKotlin` 通过。

### Phase 2｜按定稿截图实现练琴舞台

**改造入口：** `ui/PracticeApp.kt`、`ui/PracticeTransport.kt`、已有指板组件和正式 AlphaTab 宿主布局。

- 顶栏：返回图标、曲名/副标题、当前和弦与小节拍号；**不显示顶部 BPM**。窄屏仅返回图标。
- 点击中央标题：仅在曲包内多条 `PracticeSpec` 时展开简易练习选择下拉；不新增独立步骤栏。
- 上方全宽横置指板，可折叠。下方 AlphaTab 曲谱占主要区域，**无 `AlphaTab 正式乐谱 / 演奏谱面` 伪标题**。
- 进度条下方严格单排四按钮：**BPM、播放/暂停、循环、节拍**。清除试听/跟练双模式及分步控制入口。
- 以既有播放状态和音频逻辑对接按钮，不重写声音与时间线；更改布局时不改变 AlphaTab 宿主身份。

**阶段闸门：** `./gradlew :app:compileDebugKotlin` 通过；确认指板折叠和曲目切换不触发宿主重建。

### Phase 3｜删除废弃路径并收口交付

- 从 `PracticeApp.kt` 移除已无消费者的旧 `page / module / chordPhrases` 路由、废弃 Overlay、筛选状态和旧教学/试听 UI 逻辑；必要的真实播放状态继续保留。
- 删除不再被主流程调用的旧词典页面、音阶/和弦胶囊筛选组件、分步跟练组件和对应失效 UI 测试；禁止只是隐藏组件或留 `if(false)`。
- 保留音乐理论模型、曲包读写、练习编译、AlphaTab / 音频内核及其仍有意义的测试。没有必要时不动 `minSdk`、Gradle、音频、曲包脚本。
- 核对并清除因已删 UI 而失效的 import、参数和状态分支，不重写无关逻辑。

**阶段闸门：** `./gradlew :app:compileDebugKotlin` 通过；真机横屏与竖屏对照定稿图：曲谱占主面积、指板位置和折叠正确、底部四控件可操作、AlphaTab 宿主始终不重建。
