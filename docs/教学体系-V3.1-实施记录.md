## 稳定性修复依据

锁定版本 alphaTab 1.8.4 在 `AlphaTabRenderSurface.onMeasure` 中将可见区标为需要更新，布局时据此管理分块。本轮在宿主中观察实际滚动位置和视口尺寸变化，通过公开 View API 重新测量并刷新绘图面；忽略零尺寸，首次有效布局由 SDK 完成，后续隐藏恢复和尺寸变化才参与刷新。没有重新载入全谱、重建播放器或关闭分块机制。

源码核对来自固定版本 [Maven sources](https://repo.maven.apache.org/maven2/net/alphatab/alphaTab/1.8.4/alphaTab-1.8.4-sources.jar)；[官方 lazy loading 说明](https://www.alphatab.net/docs/reference/settings/core/enablelazyloading/)用于理解分块机制，实际修正以 Android 1.8.4 源码和本地验证为准。`core.enableLazyLoading=true` 保留。

P0 专用 `TeachingViewportProbeActivity` 对同一实际 SDK 表面做有/无刷新措施的滚动 A/B，输出初始、底部、中部、回顶、隐藏恢复及缩放恢复像素和 PNG，等待非空且稳定的首帧。它仅在 p0 构建中存在。未修正分支没有稳定复现原报告的整块消失，因此以上是视图区防护，不能将源码推测写成已证实根因或原故障已验收。

## 转换、来源与缺失字段

- `scripts/migrate-teaching-v31.py`：接受旧包或基线导出，输出新文件与 JSON 映射/缺失报告；默认禁止覆盖输出。
- `scripts/archive/teaching-v31/packages/`：四个未经改义的原包；`legacy-export.json.gz` 是 v103 旧素材导出。
- `scripts/audit-teaching-v31.py`：不导入生产器，独立核对迁移弦品/MIDI/精确时值/技巧及新课程的手列音高事实。现有 CSV/PDF 审计继续检查旧歌曲。
- 旧接口到新对象的映射为包内 `legacyIds`、别名和 `PracticeKey`；代码类名允许调整，用户选段与设置不靠数组序号冒充相同内容。
- 《花に亡霊》6 卡/18 版本与莫扎特 A-r2 已额外试跑转换，原谱事件保留；本地候选及具体无法构造的衔接原因位于 `work/teaching-v3-1/*migration*.json`。
- 未提供的指法、横按、和弦、动作和热身不在运行时推断；只有明确配法才计算保留指。
