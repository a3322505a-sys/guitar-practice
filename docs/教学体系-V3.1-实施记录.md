## 稳定性修复依据

固定 alphaTab 1.8.4 的原生渲染表面按实际视口管理分块。宿主监听滚动、尺寸和显示恢复，通过公开 View API 请求测量与绘制；忽略零尺寸，首次有效布局由 SDK 处理。保留 `core.enableLazyLoading=true`，不重载全谱或重建播放器。

核对依据为 [固定版本 Maven sources](https://repo.maven.apache.org/maven2/net/alphatab/alphaTab/1.8.4/alphaTab-1.8.4-sources.jar) 和 [官方 lazy loading 文档](https://www.alphatab.net/docs/reference/settings/core/enablelazyloading/)。P0 专用原生探针的 8 张稳定非空截图通过回顶、隐藏恢复和缩放比较；有/无防护像素相同，原报告的整块消失没有稳定复现。因此这是视口防护，不能声称已证明原故障根因。

API 28 软件模拟器的启动线程采样发现频繁时间分数运算进入 BigInteger/JNI。`Q` 增加精确 Long 运算与溢出回退，仍保留有理时间和原边界；独立 BigInteger 参考验证极值、约分及运算。两个曲库实例现在按同一存储根串行发布，并在写入前刷新索引，避免页面重建时重复写入同一修订；原子索引与不可变修订规则保留。

窄横屏下新增操作行曾挤压谱面，现收进顶部“练法”，全部操作仍可选；普通竖屏保留直接按钮。
