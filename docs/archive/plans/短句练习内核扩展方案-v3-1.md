# 私人吉他训练器 · 短句练习内核扩展方案 v3

## 1. 执行约束

- 目标仓库：`a3322505a-sys/guitar-practice-private`。遵守《项目规范(1).md》，以最新实现为准，默认从最新 main 建 feature 分支。
- 开工先核对 PR #3 中的 2/4 拍、十六分、附点八分和 K265 三段实现；已有代码直接复用，保留旧短句 ID 映射。若仍未合并，按当前授权确定接续方式，避免重复实现或擅自合并。
- 复用 `Sequence / Event / Session`、PCM／Player、Phrase 注册与校验、AudioTrack 帧游标。现有预备拍、降速、整句循环、独立声音开关及基础 TAB 已有，不重新建设。
- 保留音阶、和弦和既有短句；保留当前配色、页面入口、指板默认竖屏及手动切 TAB 横屏的规则。新增字段提供兼容默认值，旧数据和旧播放行为保持有效。
- 本轮限于标准调弦、无变调夹、单时间轴短句练习。架构迁移、通用编辑器／导入、在线曲库、账号、评分及整套 UI／音源替换不在范围内。
- 当前默认是尼龙弦采样。新技巧可采用可辨认的近似声音，只补必要素材；音高节奏正确、技巧可辨与主观音色满意分别验收。

## 2. 统一规则

### 时间与同步

沿用四分音符 `QUARTER=12`，无需迁移时间精度。

| 节奏 | tick |
| --- | --- |
| 四分 | 12 |
| 八分 | 6 |
| 十六分 | 3 |
| 附点八分 | 9 |
| 八分三连音中的一个音 | 4 |
| 十六分三连音中的一个音 | 2 |

- 本轮拍号为 2/4、4/4。三连音同时补齐校验、连音分组及 TAB 显示；仅放宽 `%3` 校验不算完成。不支持的节奏明确拒绝，不取整代替。
- 起音和时长由 Event 决定；切分通过起音位置、持续时间及延音线表达。拆谱不新增音频起音，记谱信息不另造播放时间。
- 保持绝对 tick 到音频帧的换算，TAB／指板读取同一 Cursor。降速保持音高，避免逐音取整累积误差。

### 演奏信息

| 维度 | 规则 |
| --- | --- |
| 发声方式 | 普通音、手掌制音 P.M.、死音分开。P.M. 保留弦品和音高；死音用 x，发出打击性弦声；休止不产生新声音 |
| 力度／重音 | 可与发声方式、技巧组合；标记与实际强弱一致，避免重复增益；默认还原旧音量 |
| ghost | 内容明确为弱奏有音高音或轻奏死音，再用上述维度表达，不增加含义不清的互斥类型 |
| 拨弦 | 单次动作明确上拨／下拨／不再次拨弦；交替拨弦落实到各起音。旧 `strum=true` 仍为下扫，上扫同时反转实际逐弦起音顺序 |
| 连奏 | 用来源音、目标音、弦号、时间及是否重拨表达滑音／击弦／勾弦；目标必须存在且关系合法 |
| 收音 | 保留 `ring / soundDuration()`；补短促收音，同弦死音也必须截断前音 |

- 同一事件支持正常弦与死音弦并存，必要时按弦覆盖力度／制音。死音区别于不弹弦，不伪装成空事件或假品位。
- 校验、PCM、TAB、指板共用解析结果；按需扩展既有 Event，不维护重复音符数据。新技巧按需更新音频缓存键。
- 纯连奏目标不重复普通拨弦；滑音在规定时间到达目标，不能用连续半音重拨代替。

### 播放边界

- 保留：改内容／速度／循环设置后停止旧会话，下次从头；声音开关即时生效；后台暂停。
- 跟练开始前预备 1 小节，默认无缝循环；示范只播一遍。次数沿用 1／4／8／持续循环。
- 暂停后从当前小节起点继续。若恢复点位于延响或连奏中，初始化必要声音；可补必要起音，谱面保留原关系，不引用上一轮残留状态。
- 句尾、选区末尾、停止及切换内容均清理旧声音；淡出不额外占拍，最后一轮正常结束。

## 3. 分阶段施工

内容随功能一起交付，每阶段形成可实际练习的完整改动。

| 阶段 | 范围 | 依赖 | 难度 | 收益 |
| --- | --- | --- | --- | --- |
| P5 | 三连音校验、制谱和播放 | 接续现有节奏实现 | 中 | 补齐常用节奏 |
| P6 | 力度、死音、P.M.、拨弦方向、短促收音 | P5 | 中高 | 可跟练的节奏短句 |
| P7 | 小节选区循环、设置记忆 | 现有 Session；可独立于 P6 开发 | 中 | 集中练难点，减少重复设置 |
| P8 | 滑音、击弦、勾弦 | P5／P6；兼容 P7 边界 | 高，声音处理不确定性最大 | 常用技巧的完整示范 |
| P9 | 内容说明与整理；可选提速／间隔 | 各阶段已交付内容 | 说明低；提速／间隔中 | 明确练习目标，减少操作 |

### P5：三连音

**需求**：准确表达八分、十六分三连音。

**规则**：

1. 复用既有 `beatsPerBar/barTicks`、十六分双符梁、附点八分及 K265 三段。
2. 在 `validatePhrases`、`TabNotation`、`Tablature` 中补连音组及其时长／成员／位置校验，正确显示数字 3、符梁和休止；保持显式休止覆盖整段的现有原则。
3. 新增一条简短原创三连音练习；普通十六分使用既有内容回归。

**验收**：2/4、4/4 下，普通节奏与三连音的声音、TAB、指板一致；延音线不重复起音，暂停／循环不漏拍或多拍；相关旧练习保持原结果。

### P6：节奏演奏表达

**需求**：能表达并听出普通音、死音、P.M.、强弱、短促和弦及正确拨弦方向。

**规则**：

1. 按统一规则扩展 Event、PCM、TAB 和指板，默认兼容旧内容；第一版做清楚、稳定的强弱，不做随机人性化或多层力度采样。
2. 死音与 P.M. 有独立、可辨的声音表现；普通弦与死音弦可混合，重音可叠加，上下扫显示与实际发声顺序一致。
3. 新增一条原创两小节节奏句，含十六分、切分／休止、死音和重音，提供简化版与完整版；另用极短 P.M. 对照片段确认音色差异。

**验收**：普通音／死音／P.M.／休止可辨；重音有效且旧音量不突变；x 无假品位，混合弦不漏音，同弦收音正确；低速可跟练，句尾及循环正确。

### P7：局部循环与设置记忆

**需求**：按小节选择练习范围，保存每条短句的速度、次数和范围。

**规则**：

1. 统一支持单小节、连续小节和整句，默认整句；第一版不做任意音符选区。
2. 复用 Session／Sequence；练习切片保留原事件和原小节映射，谱面与声音仍使用同一数据。
3. 选区开始恢复有效和弦及必要持续音／技巧状态，选区末尾收音；原短句保持不变。显示原谱范围，完整经过选区一次计一轮。
4. 用现有 SharedPreferences 按短句 ID 保存 BPM、次数、范围；保留旧 ID 映射。未知 ID、非法范围、失效旧值回到有效默认，不清空其他设置。
5. 重启恢复设置，保持默认指板竖屏，不自动恢复播放。

**验收**：K265 中间两个小节能单独循环，原谱编号／轮次／预备拍正确；核对换和弦、跨界延响、休止起始及最后一轮；切视图不重播、暂停不越界、重启可恢复、异常设置可回退。P8 完成后补技巧跨界验证。

### P8：滑音与击勾弦

**需求**：技巧的记录、声音、TAB 和指板表现一致。

**规则**：

1. 先做同弦、明确起止品位的滑音，再做击弦／勾弦，可按子项独立交付；各配一条简短原创练习。
2. 保留来源／目标音及时间关系，TAB 使用 `/`、`\`、`h`、`p`，指板明确来源、目标和当前位置。
3. 声音允许合理近似，但要体现滑动或连奏，不能退化成普通重拨。同步处理校验、暂停、选区及循环；不支持的数据明确报错。
4. 无头滑音、换弦滑音、推弦、颤音、泛音和多技巧嵌套留待具体曲目需要。

**验收**：`5/7`、`7\5`、`5h7`、`7p5` 的弦品、目标到达时间和拨弦次数正确；低速可辨，正常速度无爆音／卡顿；跨小节、选区、暂停和句尾边界有效。近似声音的限制如实说明。

### P9：内容整理与可选便利功能

**需求**：短句容易选择，练习目标明确；按需要减少手动调速和准备操作。

**规则**：

1. 复用已有分类、难度、技巧、来源、调弦条件、说明和速度标签；只补练习目标、建议起步 BPM。需要筛选时再整理技巧标签，避免重复字段。
2. 使用现有列表或简单分组，练习用途与风格分开；按简单和弦节奏／分解、单音、单技巧、综合片段组织，同句基础版和进阶版保留素材关系。
3. 自动提速为可选，默认关闭：用户设起始／目标 BPM、每 N 轮增量；仅在循环边界提速，保持音高与同步，达到目标后保持。不得把完成播放当作已经掌握。
4. 循环间隔为可选，默认 0，以当前拍号的小节计；读同一会话时间，间隔不计练习轮次。
5. 提速与间隔不阻塞 P5–P8，未做明确保留待办。

**验收**：已支持类型的新短句只需录入并注册数据，不改播放器／UI 核心；新增短句有目标、起步速度、演奏提示及来源／改编条件。若交付提速／间隔，核对上限、轮次、暂停继续及关闭后原行为。
