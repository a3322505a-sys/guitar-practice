### R1：保留的功能基线

按最新代码核对现有六类音阶练法的具体名称和行为，不凭本方案重新发明。README 描述的功能包括：

- C 大调五型、A 自然小调视角；弦范围／一八度选择；四分／八分音符。
- C、Am、G、Em、D、Dm、E、A 的具体开放指法；逐弦检查、两和弦转换、规则下拨、简单分解。
- 点音探索、听示范、跟练、撤去提示后自行对照；不判题、不记录学习成绩。
- 默认 60 BPM、4/4、跟练预备 1 小节、4 次循环，示范 1 遍；保留已有循环选项和示范音／节拍声开关。
- 暂停或进入后台停止推进与发声；手动继续从所在小节起点恢复；两个声音关闭时视觉拍点仍可推进。
- 保留已有使用设置；新增视图偏好可保存，不引入练习成绩或跨项目档案。

若最新实现与上述描述不同，先写明差异及依据。除本轮明确变更外，以已确认的最新行为为准。

### R2—R3：最小接口与统一数据

以下是职责契约，类型名、文件数和实现形式由施工 agent 按现有代码决定，不要求机械套用接口类。

| 边界 | 输入／输出 | 必须守住的职责 |
| --- | --- | --- |
| 音乐数据 | 调弦、调性、指型、具体和弦位置 | 保存音乐事实；不依赖页面尺寸、颜色或播放器 |
| 练习编排 | 练习配置 → 有限练习序列及循环规则 | 决定演奏什么、在哪弹、何时开始、持续多久；不生成像素坐标或 PCM |
| 播放控制 | 序列与播放命令 → 会话状态、统一播放位置 | 负责开始、暂停、继续、停止、循环和释放；同一会话只有一份播放进度 |
| 音源与渲染 | 演奏事件与音源配置 → 声音数据 | 管理素材、映射、音长处理、扫弦展开与混音；更换素材不改练习语义 |
| 视图与页面 | 序列、播放状态、显示选项 → 展示与用户操作 | 负责指板、和弦图、六线谱和布局；不另起计时器、重选指法或重新编排练习 |

共享数据至少能表达：

- 稳定的事件标识、事件／和弦分组关系、弦号、品位、音高，及已有的必要指法信息。
- 统一音乐时间单位下的起点和时值、小节边界及拍号；继续沿用已有整数 tick 或等效精确表示，不用累计 UI 帧数推导节奏。
- 单音、同时发声、逐弦／分解和休止；全局调弦与必要的和弦名称等元数据。
- 播放状态、循环次数／当前轮次、当前音乐位置；显示层从中推导当前与后续目标。

同音高可出现在多个弦品位置，六线谱必须使用序列已有位置，不得仅凭音高重新选指法。一个和弦可包含多个音，不能把“当前事件”限制成只能高亮一个音。

扫弦在谱面上可以显示为同一拍的和弦及扫弦方向，音频层可按弦序加入演奏偏移；两者仍须关联同一音乐事件，不能把微小扫弦间隔误写成额外节奏音符。休止和延音必须与真实编排相符。

继续使用已有播放器的实际播放位置机制；如有无声模式，统一由播放控制层提供等价时间来源。视图重绘、重排或切换不重建播放会话。布局依赖窗口尺寸，音乐序列不依赖窗口尺寸。

音源入口支持本轮实际素材更换即可。优先使用配置、数据类或小型接口，不要求运行时音源商店、多格式插件或虚构的第二套音频引擎。

### R4—R6：界面与六线谱规则

主屏结构由上至下组织为：

1. 紧凑导航与配置摘要：当前音阶／和弦、练法，指板／六线谱切换。
2. 主练习区：完整图示或谱面，当前与下一目标、拍点及循环进度。
3. 紧凑控制区：速度、示范／开始／暂停／继续等当前有效操作，结束入口保持易找。

音阶／和弦入口保留，但不与播放状态、按钮堆成三层高底栏。使用正常布局约束和系统安全区，避免固定底栏覆盖图示。

配置详情放入可展开面板或抽屉：调性、指型、练法、范围、节奏密度、循环、提示与声音选项均保留。五种指型和全部和弦必须容易发现，不依赖一串无提示的横向裁切按钮。教学解释按需展开，短提示靠近相关操作。

播放期间更换视图仅改变展示。修改会改变序列的配置时，先明确结束旧序列并回到待开始状态，再应用新配置；不得一边发旧声音一边展示新谱。速度与循环沿用已有可靠行为，并在控件附近表达生效时机。收起或打开设置面板不应触发重播。

“撤提示”同时作用于两种视图：隐藏目标答案性内容，保留拍点、控制和必要的空白结构；恢复提示不改变序列和进度。不得通过切换视图绕过当前提示设置。

六线谱要求：

- 六根弦，上方为 1 弦、下方为 6 弦；数字为品位，0 表示空弦。未弹弦留空，不因没弹就写成闷音 X。
- 使用可读的标准节奏表达，包括本轮实际需要的符干／符尾或符梁、休止、小节线；需要跨拍／跨小节延续时使用正确的连音线。只覆盖现有练习所需符号，不扩展为完整制谱引擎。
- 单音、和弦、扫弦与分解必须表达真实顺序、同时性和持续时间；和弦名称可作辅助，不能用名称代替六弦位置。
- 平板横屏优先多小节、多行排布；按可读宽度动态决定每行小节数，不锁死数量。手机六线谱可减少每行小节，不把整段压缩到不可读。
- 让当前小节保持可见，提前展示下一小节；按小节或谱行跟随，避免每个音触发整页跳动。循环边界、预备拍与暂停状态清楚。
- 保留已有指板点音能力，和弦图可继续使用；不强求新增六线谱编辑、拖拽改音、导入导出或复杂点击定位播放。

### R7：音色规则

- 目标是自然的吉他拨弦质感，同时保证练习所需的音高清楚、起音明确、音量均匀和连续听不刺耳。优先干净音色，避免靠重失真、大混响掩盖素材本身。
- 先核实当前素材与音域映射，再试听少量适合当前音域的候选，选定一套完成接入。记录来源、许可、必要署名及资源体积；不从来源不明的音频直接取样分发。
- 新素材适配可包含分音域映射、音长／释音和混音调整。是否需要多个采样由实际听感决定，不预设高成本采样库或重写整个音频系统。
- 用相同内容、速度和接近的感知响度制作新旧对照：一段覆盖常用音域的单音、一段开放和弦、一段简单分解。避免单纯提高音量造成“更好”的假象。
- 软件检查只能验证资源和输出可用，不能证明“更像吉他”。有试听能力时记录听感判断；无法试听时明确标为待试听，并提供对照片段，不虚构主观结论。
- 不要求把实时切换音源做成新产品功能；开发侧可用配置或资源映射完成替换。对照片段用于交付判断。

## 4. 最小验证与交付停止线

### 核心验证

- 数据与时间：针对新边界补必要检查，覆盖同音高不同弦品、和弦多音分组、时值／休止及循环位置；复用现有测试，不为简单布局或数据搬家堆测试。
- 功能抽查：音阶选择一段含空弦或跨弦的现有路线；和弦覆盖逐弦、转换、下拨和分解。检查序列、谱面与声音对应，不遍历所有参数组合。
- 状态抽查：播放中切换视图、暂停再继续、后台再回前台、重来与结束；关闭两种声音后验证视觉仍推进。窗口变化不能额外开始播放或重置练习。
- 界面抽查：代表性手机竖屏与平板横屏各一组；补看一次平板竖屏或窄窗重排，排除覆盖、裁切和难读。没有实体平板时可用对应窗口的模拟器并如实标注。
