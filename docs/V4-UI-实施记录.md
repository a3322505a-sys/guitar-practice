# V4 前端 UI/UX 重构

基线：`codex/native-teaching-v106` / `c5e6355`（v107）。实施分支：`codex/v4-studio-ui`。

## 需求与规则

按 V4 设计规范及用户补充的六项工程约束，依次完成 Phase 1–4，各阶段编译成功后独立提交。以平板持琴练习为主要场景，兼顾 360 dp 手机。完整词典与教学内容渐进呈现；不增加档案、评分或强制任务。

- 保留原生曲包、练习 ID、编译器和单一 alphaTab 时间轴。
- 不新增依赖。响应式使用现有 Compose 约束，断点为 600 / 840 dp。
- `forest_daylight` 使用指定的全部固定色值。
- 迁移真实回调；模态界面拦截遮罩和原生谱面触摸。
- 保留测试语义锚点；最终执行单测、Lint 和 Debug APK 构建。

## Phase 1：设计系统

实际类型为 `ThemeTokens` / `ThemeMetrics`。增加背景层级、乐理语义色及尺寸字段，保留旧字段映射。主题收敛为黑金录音室（默认）、暖木工坊、森林日间；废弃 ID 回退并持久化默认值。更新主题与迁移测试。

验证：`./gradlew :app:compileDebugKotlin` 通过（JDK 17，未增加依赖）。

## Phase 2：展示投影与卡片

增加 `ExerciseCardUiModel`，保留真实 PracticeKey，把标题、教学分类、版本、技巧与 BPM/小节信息分开。转换练习投影为单一分区；无边框卡片采用左侧选中条和层级背景。600/840 dp 分别切换双列/三列；标题固定 16 sp，大字体允许完整换行。

验证：`./gradlew :app:clean :app:compileDebugKotlin -Pkotlin.incremental=false` 通过。干净构建排除了当前工具链增量缓存中旧顶层声明引发的重复符号。

## Phase 3：统一工作台与词典

使用显式密封路由区分课程、和弦词典和音阶词典。手机底部 88% 高度，宽屏在右侧提供可容纳双栏的工作台；偏好面板宽 420 dp。词典预览固定，配法/Box 横向切换，筛选区独立滚动。保留所有根音、性质与配法；加入全部来源筛选和当前练习重点/完整范围操作。

模态窗口使用同一显式可点击 scrim；原生谱面保留单一固定挂载点，增加独立输入开关，关闭输入时取消在途手势，不变更谱面或音频实例。工作台不再压缩舞台或移动谱面。

验证：`./gradlew :app:compileDebugKotlin -Pkotlin.incremental=false` 通过。原生输入屏蔽回归测试随最终测试运行。

## Phase 4：全宽舞台与双层播控

主舞台外边距归零，移除外层和图示容器描边；新增当前和弦/调式与提示筛选条、根音外圈与蓝调特征音色。正文下限 14 sp，标签 12 sp。原生谱面保持同一挂载点与标准权重槽位；模态期间取消在途触摸并冻结输入。

`StageTopBar` 保留当前练习入口与三项固定操作。`PracticeTransportDock` 将原有版本、热身、衔接、领奏三档、渐隐、倒序接龙与范围移入策略条，保留示范、跟练、暂停、重来、结束、循环和混音。速度面板提供六档 BPM 步进与五档倍速；混音保留音乐总音量，并独立调节领奏、伴奏和节拍。

词典配法独立于教学和弦卡组进入练习；外部选卡与用户滑动分页分别同步。未编译的曲库卡片展示曲包原有段落信息，避免把占位谱面的长度误报为真实小节数。

历史 Debug 测试中已删除的曲包、旧指型表和旧导航入口改为当前原生曲包或独立记谱谱例；保留数据、时间轴、音频、手势、卡片选择与设置持久化的实际断言。新增输入冻结回归覆盖，并保留可独立命中的测试锚点。

应用 ID：`com.a3322505a.guitarlearning`；版本：`1.3.0 / 108`；最低 Android 8.0 / API 26。未新增 Gradle 依赖。Debug APK 使用调试签名；原长期签名的覆盖安装与真机音频表现需在持有签名的设备环境验证。

## 最终验收入口

四阶段均在提交前通过 Kotlin 编译；Debug 渲染、交互、原生输入冻结与导入回归已完成迁移。完整验收已加入 `Android core / verify`，执行以下检查，并保留原 compare/release/p0 核心检查：

```bash
./gradlew :app:compileDebugKotlin
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```
