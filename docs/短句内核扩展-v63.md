## 播放与数据边界

继续使用 QUARTER=12、绝对 tick→帧换算和同一 Cursor。三连音必须显式登记三个等长成员，可以含显式休止；不支持的细分拒绝。制谱分段仍只引用原起音，不创造音频起音。

死音由弦号单独表达，没有假品位；P.M. 保留实际音高，采用低通和较快衰减。死音为确定性短噪声模拟弦上打击。默认 velocity=1、无重音、普通采样和旧 strum=true 下扫维持旧行为；按弦力度只计算一次。

滑音采用连续相位采样变调，目标到达指定起音时刻。击勾弦保留来源音的连续样本，在目标附近平滑转到目标音高，不重新触发普通拨弦包络。这是可辨识技巧的合理近似，没有录制击勾弦音源或模拟真实吉他的全部音色细节。每个来源事件第一版仅允许一条同弦技巧关系；嵌套、无头／换弦滑音、连奏内改变 P.M. 等未支持数据明确拒绝。

选区不删改原事件或记谱关系。Pcm 在每轮的选区边界裁切声音，并在边界内做 5 ms 淡入／淡出；预备拍不漏入上一段音。选区起点可以恢复有效和弦和来源在边界前的持续／连奏声部，不依赖上一轮残留。暂停继续仍从当前小节起点，保留当前轮次与原谱坐标。

参数存入原 practice-settings SharedPreferences，键以短句 ID 隔离；不清空旧提示或声音开关。旧 K265-1…6 选择映射到 K265-A…C，未知 ID 回 S01；失效范围／数值／类型回有效默认，不清除其他短句参数。Activity 重建用原 rememberSaveable，真正重新启动从存储读取设置，不自动开始播放，默认指板竖屏。
