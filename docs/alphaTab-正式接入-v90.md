# alphaTab 正式接入：v90

接续 `01a13c64-4f6a-78e1-bd6a-52b86b8a67a3` 的 v86 P0。2026-10-15 用户明确要求继续自主推进重构，最终由用户实机验收；本轮据此继续接入 P1–P4，不把未完成的真人听感当成自动迁移的阻断。使用已有 worktree `work/alphatab-p0`，新分支 `codex/alphatab-practice-v90`；远端 main 重新 fetch 后仍为 `09995e6` / v81，没有开放 PR。主目录 v82 的未提交工作保留。

## 正式链路

- `MainActivity → PracticeModel → AlphaPlayback`：正式入口只创建 alphaTab 引擎。旧 `Player` 与自研 TAB 仍可编译用于迁移前测试，正式 App 不调用这两条运行路径。
- `PracticePlayback` 是现有 Compose 工作台的操作/状态契约。原内容选择、音阶五型、和弦教学、根音/构成音、手指编号、开放/禁弹弦、逐弦和整和弦试听、短句、原曲包管理保持。
- `AlphaScoreAdapter` 将现有认可的 `PerformancePlan` 展开路线适配为原生 `Score → Track → Staff → Bar → Voice → Beat → Note`。这是数据来源兼容层；`Session` 元数据仅供已有界面读选区/标签，不使用旧 PCM、设备帧时钟或 TempoMap 推进播放。
- 原 GP 直接由 SDK 解析，不绕经旧音乐内核。正式六线谱、声音、播放位置、变速、预备拍、节拍器和循环边界均由 alphaTab 执行。指板以引擎生成 MIDI 的音符起止区间查询引擎回报的 tick，包含多个声部和休止中的持续音；弦号反转为 `7 - nativeString`，保留调弦与变调夹；适配的吉他五线谱高于实际发声一个八度，MIDI 实音不变。
- 原生控件在指板/六线谱两种视图中始终挂载，隐藏时只改变可见性。切视图不销毁会话；后台和音频焦点丢失暂停。点音使用同一引擎 `playBeat`，不替换主曲，持续练习期间不触发试听。

## GP 曲库与数据保留

`files/gp-library` 保存原 GP 副本，以 SHA-256 作为身份，每首曲一个 `AtomicFile` JSON 记录。先完整读取/解析，再保存副本，最后发布记录；错误文件不进入列表。同内容重复导入返回原记录，保留速度、选段、轨道、次数及显示/声音偏好。重开前核对副本字节数与 SHA-256；损坏报错。

入口提供导入、搜索、最近练习、选择和删除确认。删除只作用于具体受管副本和该曲记录，不根据原文件名构造删除路径。文件上限 96 MiB；开放 GP5、GPX、ZIP/GPIF 的 GP 文件，选择六弦且 MIDI program 24–31 的吉他轨。此前真实试读过的 53 份样本和 GP5/GPX/具体 GP8 的 P0 证据保留，不能据此承诺全部 GP8 变体。

选区按 alphaTab `tickCache.masterBars` 的实际演奏顺序列出每次经过，区分重复小节。选择的完整连续经过转为引擎 `playbackRange`；跨入上一小节延音或连奏的起点要求前移。选段结束截断剩余延音。次数由 `playerFinished` 回调计数，在最后一轮前关闭循环，没有软件定时器重新起播。

原 `files/songs`、预装 `.gpractice`、Repository、全部 `practice-settings` 原键和来源锚点继续使用；不清空或迁移目录，不删除原键。GP 偏好使用新曲库记录和 `gp-library-ui`。原曲包不需要用户提供原 GP 再导入。

## 转换与验证边界

时值使用原符值、附点和连音；必要拆分引入延音连接，不追加拨弦。不支持的嵌套连音、速度/力度渐变、特殊摇摆、复合装饰音、反复拨弦等报错并保留原资料。已安装四个曲包和内置教学素材均在本轮转换核对范围内。

旧资料的标准音符力度及截音/延响截止在 SDK `midiLoad` 接入点适配，仍由同一合成器消费；推弦、滑音、连奏、装饰音等保留引擎的奏法生成。音色改为随包 SoundFont 的 GM 吉他。装饰音符形/抢拍、奏法延响、刷弦和原尼龙采样的听感差异仍需真人核对，不声称所有实际声音已逐音证明与原版相同。

针对性自动检查覆盖：所有可生成的原音阶调性/五型/练法/1–3 音节奏/音域、基础和弦和内置短句的弦品/音高及完整路线时值；四个预装曲包全部练习无原 GP 转换；多声部持续音跨休止、延响截止；真实 SDK 导出 GP 的持久导入/重启/重复/失败/删除/损坏检测；原预装目录和旧偏好恢复。只复用相关旧用例，没有把旧 TAB 截图测试当作新排版验收。

发行包使用现有长期签名，身份不变，不打包桌面私有 GP 样本，不声明 INTERNET；字体、音色和许可随包安装。最终测试数量、lint、包哈希、模拟器观察、数据保留证据及截图见 [本地交付](../../../output/alphaTab-v90/README.md)。

## Android 运行预检修复

v87 首次运行捕获了 SDK 1.8.4 的 `loadedMidiInfo` getter 自递归：订阅 `midiLoaded` 时求初值导致 `StackOverflowError`。v88 移除该订阅，只监听经 P0 验证且每次 MIDI 加载后触发的 `playerReady`，没有改动第三方二进制。预检包与日志保留，v88 已取得 Android 启动与原生引擎就绪记录；最终交付 v90 还避免声音开关随界面刷新重复下发，并让点音试听复用所选轨道已加载且未静音的通道/音色；运行边界见交付记录。

待用户核验连续两轮选段、暂停继续/重来、变速、预备拍/节拍器；简单和复杂多声部 GP、跨小节延音、不同调弦/capo；音阶、和弦试听和已有短句；手机横屏/平板、切视图、重启离线、覆盖升级后原数据。软件模拟器的音频欠载和缓慢不能代表目标设备性能，也不能证明音色或严格同步合格。
