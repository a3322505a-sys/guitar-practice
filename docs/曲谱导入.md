# 歌曲资产导入与审核

本流程为编译期工具，App继续消费原 `Phrase/Sequence`。原谱、来源事实、教学加工、目录入口分开保存。主界面不自动展示所有来源材料。能力与依赖矩阵、兼容边界见 [v72记录](v72兼容与施工记录.md)，原件许可见 [来源与许可](来源与许可.md)。

## 现有三条路径

| 来源 | 专属适配与注册 | 受保护输出 |
| --- | --- | --- |
| GP 斜阳 | `import-shayou.py`；5条完整源段；`Phrases.kt`注册；人工 `ShayouChords.kt` | `Shayou.kt`、`shayou-gp.csv` |
| GP 卡夫卡 | `import-kafka.py`；28条源段；`KafkaPractice.kt`整理7核心/6版本；`Phrases.kt`维护目录；`PhraseSettings.kt`兼容旧ID；`import-kafka-chords.py`依赖导入器的read/SOURCE | `Kafka.kt`、`kafka-gp.csv`、`kafka-expressions.csv`；50指法由现有和弦路径维护 |
| 审核PDF Your Trip | 原PDF旁逐事件审核 → `scripts/score-data/your-trip.json` → `generate-your-trip.py`；6条入口 | `YourTrip.kt`；独立 `your-trip-pdf.csv`只作来源校验，不由生成器重写 |

共享代码是 `scripts/song_assets/`：GPIF引用图读取、Fraction节奏、Kotlin音位列表、来源指纹、半开窗口校验、覆盖诊断和报告。专属适配器保留原技巧、延音合并和输出格式。三首原Kotlin、GP CSV及人工和弦/目录/设置代码是兼容参照，禁止为了“生成通过”手改夹具、降低保护哈希或自动覆盖人工分析。

## 先生成候选，再审核

Python 3.11，仅标准库。从仓库根目录执行，`--source`指定自己的本地原谱；每次使用新的空候选目录：

```powershell
python scripts/song-assets.py --manifest scripts/song-manifests/shayou-v72.json --source '<本地斜阳GP>' --output work/song-assets/shayou-review
python scripts/song-assets.py --manifest scripts/song-manifests/kafka-v72.json --source '<本地卡夫卡GP>' --output work/song-assets/kafka-review
python scripts/song-assets.py --manifest scripts/song-manifests/your-trip-v72.json --source '<本地Your Trip PDF>' --output work/song-assets/your-trip-review
python scripts/test_song_assets.py
```

原有三个脚本仍可直接执行，但其默认入口会生成原路径文件；日常审核优先用上面的候选命令。通用命令不覆盖非空目录、不写现有App文件、不注册入口。原谱SHA必须与清单一致；PDF还检查已审核JSON的指纹，改转录数据后必须重新对照原谱审核。

候选目录含：

- `source-practice.json`：工具侧IR。`sourceFacts.events`保留原书面起音、时值、弦品、死音、延音目标、实际MIDI（GP）或页码/pdfX（PDF）；`practice`保留输出事件、links/tuplets、实际窗口/拍号与教学留空；`catalogue/teaching`只提供人工注册和选材关系，不驱动App。
- `report.json`：来源格式/文件名/哈希、处理与跳过事件数、总tick、分类诊断、候选Kotlin/CSV哈希、与v72保护输出比较以及命令模板。
- `app/...`：候选Kotlin/CSV，现有曲的输出哈希必须与保护值相等。`compatible`表示这项输出比较成立，仍需看近似/审核诊断；不代表原曲真实性、听感或设备验收。

GP报告的事件计数为原CSV音头/休止行（同拍多弦分别计数，卡夫卡去重/纯休止覆盖另见适配器报告）；PDF为原书面事件数。两者不能直接比较。`skippedEvents=0`指所选/已审核来源集合中的事件未因未知字段丢弃，不指全曲全部轨道/所有PDF小节都变成练习。

## 清单、句界和来源位置

`scripts/song-manifests/`现有三个清单固定 songId、格式/源SHA、轨道、来源ID、窗口、已有目录和输出指纹。GP原声部显式选择，卡夫卡GP索引0为未编号弱起，正式编号与索引1–148相同；斜阳来源编号从1起。不能假定GP第一个轨就是吉他。

窗口统一左闭右开 `[start,end)`，`start/end={bar,tick}`，tick是来源小节内的12 tick/四分音符。整小节可用后一小节tick0结束。共享 `window_offsets`按实际拍号累加，卡夫卡第81小节为24 tick，不能固定乘48。

Your Trip旧数据 `first/last/start/end`里的end是最后小节内**不含**的终点。清单精确映射：YT-GROOVE止于10/12；YT-ARPEGGIO起于10/18、止于25/48；YT-LEGATO止于33/24；YT-RIFF起于33/24。保留全小节练习格，窗口外变成 `practicePadding`，报告记录具体区间；源事件仍原样保存在sourceFacts。它不是原谱休止。跨事件切句、选中延音目标却丢失来源、跨窗连奏或ringEndTick均阻断；未实现自动截音策略。

卡夫卡来源素材、教学组合与主界面核心入口保持三层：7核心/6版本由 `KafkaPractice`维护，包括裁纯静音尾、L/M同声部结尾拼接；来源KAF-*仍可引用，旧选择交给practiceNamed恢复，不能自动把28源段注册为主按钮。新素材也必须显式决定目录/版本及旧设置策略。

## 覆盖与拒绝

GP门禁逐选中轨检查Track/Staff、MasterBar/Bar/Voice/Beat/Note/Rhythm、Properties、枚举/属性及自动化；诊断定位轨道、GP master索引、Beat/Note ID、字段/值。现有非渲染GP元数据使用受控的 `gp-reviewed-metadata.json` 精确结构指纹，新增字段/值不自动加入白名单。曲式标记属于来源音乐，调号记录为审核事实；仅明确排版字段列 `ignored-layout`。

报告分类：`supported`、`unsupported-blocker`、`review-needed`、`ignored-layout`、`approximation`。GP自带音色/RSE/同步点、现有注释等不冒充排版：报告其既有审核/近似限制，App仍用原采样音源；未知新值阻断。不能将“按音符/MIDI复现”说成原GP音色/伴奏录音的完整复刻。

阻断包括未知奏法/枚举/嵌套属性，反复/跳房子/曲序路线、段内或渐变速度、多活跃声部、调弦/partial capo、不支持的节奏、弦品/MIDI不一致、跨事件边界以及丢失连奏/延音。PDF未知字段与技巧、不完整小节、异常三连音、选窗截断也阻断。旧专属适配器的结构限制继续有效，门禁成功不意味着所有GP版本都受支持。

## 增加下一首歌

新增审核PDF数据可复用现有生成器，无需复制Python：

1. 保留原PDF，计算SHA；在原谱旁审核单一声部、页码、pdfX、标准调弦、capo、4/4与每拍12 tick的书面事件。数据结构参考 `score-data/your-trip.json`（此PDF适配器目前仅4/4、当前奏法和十六分显式三连音）；它不是OCR。
2. 复制一个**数据清单**，设新的songId、源SHA、profile=`reviewed-pdf`、tracks、objectName（ASCII大写开头）、segments稳定ID和准确start/end；`reviewedData`指向审核JSON。删除旧曲protectedOutputs，填自己的reviewedDataSha256。音乐/教学文案仍在parts里，源演奏事件不要用文案覆盖。
3. `python scripts/song-assets.py --manifest <新清单> --source <原PDF> --reviewed-data <审核JSON> --output <新候选目录>`；新曲结果为review-needed，先对照原谱及IR，再编译/渲染确认。便携测试包含合成数据的新曲候选演示，不声称已新增真实歌曲。
4. 审核通过后才把候选Kotlin纳入App并显式注册 `Phrases`/目录/版本；维护独立来源夹具，测试音高、节奏、范围、技巧、存储和显示契约，更新来源与许可。工具不自动命名和弦，不新增和弦卡或第二播放器。

新GP须复用 `gp_graph/rhythm_ticks/audit_gp`，根据实际源版本审核字段与奏法、确定选材适配；现有shayou/kafka profile固定它们的结构和范围，**不能改songId就拿来导入任意GP**。只有新源确实需要不同语义时才加小适配器与反向样本，不复制整套读取/报告，也不自动扩大白名单。变速、反复、非标准调弦/多声部等当前能力外内容保持待办并阻断。
