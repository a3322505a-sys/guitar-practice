# 当前曲谱导入

当前歌曲唯一运行时来源是 `.gpractice`。使用 [曲包生产手册](曲包生产手册.md) 和 [v1协议](../contracts/song-package/v1/README.md) 的 inspect → normalize → 独立来源审核 → validate → pack 流程；在 App 的练习设置 → 本地曲库导入，不生成歌曲 Kotlin、不修改 Phrases、不重编译 APK。

`app/src/main/assets/song-packages/` 预装四首迁移曲包。启动时走与手动导入相同的验证、不可变修订和原子索引；目录、教学版本、指法及播放计划均由现有 Repository 读取。只有预装曲包可以声明用于旧安装设置的全局 legacyIds；外部歌曲 alias 仍限定在自己的包命名空间。

基础和弦、基础音阶、原创通用教学及《七个Block》技巧练习保持内置。卡夫卡已废弃。旧CSV、已审核PDF转录及原件保留用于来源审核，旧Kotlin生成器与导入流程见 [历史归档](archive/legacy-v76/曲谱导入-v72.md)，不再作为当前生产步骤。
