## 实现

- 理论、实体配法、替代关系分开。和弦词典覆盖全部 12 个音高主音，另保留 D♯/G♯/A♯/D♭/G♭ 的准确异名拼写；每种定义都有经逐弦校验的实体配法。Fm、B、Bbm、F♯、F♯m、G♯m 另有局部横按或四弦同性质配法，改变低音时明确标为斜杠名。大/小三、大/小七、属七、挂留、加九、六和弦、减三、减七、半减七、小七加十一、明确省略、Power 和八度独立命名。字典记录实际六弦音名/八度、最低低音、O/X、1–4/T、横按、配法名和适用条件。完整数量及检查结果见 [词典审计](validation/v107-dictionary.json)。
- E/A 型移动只作用于显式封闭模板，开放配法逐项编写。C♯m7 的开放配法是 x46600；x46650 归 C♯m。244200 是 F♯m7(add11)，xx4432 是 Bm/F♯，xx3331 是 B♭/F；Fmaj7 的 F3 局部配法和含 F2 的可选 T 配法分开。斜杠非和弦低音参与实音检查，不被改称转位或遗漏。新增常用开放大七/属七及完整加九配法；x32310 缺五音 G，明确写 C7(no5)，完整 C7 另有已验算封闭配法。
- 五类音阶共有 60 套音高、音名/级数和完整指板落点，300 个封闭位置：五声五 Box、七声五个 CAGED 关联位置、布鲁斯在五声骨架中加入真实 ♭5。每个位置检查其整个 MIDI 音域内部无漏音；关系大小调保留各自主音与级数。开放 C/Am、G/Em、D/Bm、A/F♯m、E/C♯m 单独计算、配指和验证，不移动开放弦。
- 完整词典从“和弦教学 → 查和弦词典”和“音阶教学 → 完整音阶词典”查询；默认教材保持原六个入门调性及 21 个配法。字典按根音/性质缩小结果，不把全量词典平铺给初学者。定义别名和替代类型可查询，简化不会隐藏真实名称。
- 标准库增加三组 C 大调功能进行（1–5–6–3–4–1–4–5、4–5–3–6–2–5–1、4–5–6），当前标准库 89 条记录。保留 v106 三套原创示范包，另加入完整“每日练习”。全库共 119 条记录，包含版本和隐藏衔接。
- “每日练习”只有自由选卡、版本、速度、循环与连练，不添加签到、评分、任务门槛或自动升速。选择曲包时四个模块的卡片一并可见；四卡仍可单练。
- 手动领奏 100% / 30% / 0% 与主动选择的循环渐隐并存；伴奏有独立音量/静音，现有选轨独奏、音乐总音量和节拍器音量继续使用同一个 alphaTab 播放器。单轨练习不受遗留领奏/伴奏设置静音。待机预览及下一事件/下一和弦按当前循环窗口计算，倒序接龙进入 7–8 小节后不会继续预览第 1 小节。
- 五文件协议继续复用 SongCodec/PracticeCompiler/alphaTab。T 在本协议用整数 5 表示，独立声明 `teaching.thumb.v1`；映射至 SDK 的 `Fingers.Thumb`，不会把 O 的 0 当成拇指。Barre 仍只用 1–4。内置包增加修订至 2；同一个原生曲库存储根保留 v106 ID 和设置关联。

## 每日练习曲包

编写源为 `scripts/song_package/daily_practice.py`，由 `scripts/build-teaching-v31.py` 编译为 `daily-practice.gpractice`。共 **36 个源小节、144 拍、4 张卡片、基础/进阶两版**，另有两版连练及 DP-04 两个隐藏衔接记录，共 12 个练习记录。

| 卡片 | 谱面与边界 |
| --- | --- |
| DP-01 / 8 小节 | 前七小节每小节六个八分加一个四分，按三音动机问答；末小节 C3（5 弦 3 品）全音符。进阶增加跨弦，不强制全程保留四指。 |
| DP-02 / 8 小节 | C–G/B–Am7–Fmaj7；前三个低音 C3→B2→A2 下行，之后 F3 收束。基础扫弦；进阶分解在 5–7 小节第 3 拍分别加入 Cadd9/Gsus4/Asus2，第 4 拍还原。Fmaj7 分解不弹 X 的 5 弦。 |
| DP-03 / 8 小节 | 独立伴奏 C–G/B–Am7–Fmaj7 ×2；领奏前三个重拍落 E/D/C。进阶第 4 小节 A3→C4 同指滑音，随后重整为 5 品 Box 1；第 5 小节有明确击/勾关系。按两小节设置接龙边界，先 7–8，再 5–8，事件始终正向播放。 |
| DP-04 / 12 小节 | F5–G5–A5–C5 驱动、Fmaj7–G6–Em7–Am 展开、F/G/A/E/A 八度 Riff 收尾。进阶 A 段每小节八个八分，前五个 PM、后三个开放；基础用慢速四分。八度只弹 5/3 弦，中间 4 弦 X；最后显式切音与休止。4→5 衔接按完整两小节循环。 |

连练谱面只有统一 **82 BPM**，可手动改变；不插入卡片间硬切变速。独立卡片有各自推荐速度，DP-04 进阶为 110 BPM。拍数、变体、配指、实际低音、和声生效区间、PM、八度静音和技巧关系由独立 [曲包审计](validation/v107-native-audit.json) 逐项检查；[编译内容统计](validation/v107-native-data.json) 保留五包结果和来源文件哈希。
