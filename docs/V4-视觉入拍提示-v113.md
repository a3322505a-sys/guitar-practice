## 视觉事件来源

引用 AlphaTab 1.8.4 **公开事件接口**：

```kotlin
api.midiEventsPlayedFilter = alphaTab.collections.List<MidiEventType>(MidiEventType.AlphaTabMetronome)
api.midiEventsPlayed.on { played -> /* listen AlphaTabMetronomeEvent */ }
api.playerPositionChanged.on { event -> /* first non-seek main position = go */ }
```

`midiEventsPlayed` 在音频播放缓冲消费后派发，含 count-in 期间的节拍事件。事件自带 `metronomeNumerator` 从 0 计数，用以驱动红灯（前面的预备拍）和黄灯（预备拍最后一下）。正式时间轴的第一个非 seek `playerPositionChanged` 驱动绿灯，随后按当前拍号一个拍时值的 engine tick 关灯。

所有 UI 事件仍通过主线程和现有 `callbackEpoch` 防过期机制，不新增 UI 时钟、SoundPool 或定时任务。切谱、暂停、停止、播放结束、失败时清理灯状态。
