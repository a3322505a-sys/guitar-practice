## P2 整张和弦卡

十二个和弦沿用 `Chords.all` 顺序。一张卡包含和弦名、组成音、指法图、试听、当前播放状态和点音反馈；左滑下一张、右滑上一张。`HorizontalPager` 每次手势最多一张，以 `settledPage` 连接 `firstChange`，只有实际换到不同内容才结束旧播放。首尾不循环，边界手势、打开设置或选择当前和弦不清除播放。设置索引保留，指板视图增加 48dp 的上一／下一按钮和无障碍名称。

主卡占原 P1 的完整宽度；上一／下一卡的背面在主卡后各露 6dp 窄边，不参与主卡宽度分配，窄于 300dp 的内容区不露边。侧层不处理点击。整卡内容一起横移，图形本身不做竖向翻页。保留 P1 的整页滚动回退，Canvas 与点击坐标使用同一几何。

## P3 四组 A→B→A

仅调整 `Routes.scale(CONNECTION)` 及其路线辅助函数，其他练法保持原样。在两个相邻型的共享主音中选择换型点，以连续的调内 MIDI 音高建立去程；每个音高可以有多个实际弦品候选，综合品位移动与跨弦次数选择位置。回程从转折音继续下降，重新在对应指型候选里选弦品，不把原坐标列表直接反转。候选只允许同弦或相邻弦移动，要求两型均有独占位置；回程到 A 的独占位置后再回到起始音位，转折音只起音一次。

仍使用每拍 1／2 音、示范、预备拍、1／4／8／持续循环、暂停继续和句尾补齐小节。到达 B 不提前结束 Session。`re` 不接回 `mi`，没有新增判题、成绩或强制补练。

八组 C 大调／A 自然小调的逐音弦品、MIDI、去回方向、建议用指与共享主音见 [路线 CSV](指型往返路线-v60.csv)。数据由实际生产函数生成，完整路线为 11 或 13 音；品位只表示实际演奏坐标，没有变调夹偏移。建议手指 0 为空弦，1–4 为食指至小指；开放型按第一把位，其余按各弦起点推算。去程共享主音后进入 B，回程共享主音后回到 A。

**实琴验收尚未完成。** 位置选择减少不必要移动并满足代码约束，不能单凭这个代价函数或音高检查证明所有手型自然。CSV 用指为建议，真实左手换把、低速连续弹奏与主观听感仍需实琴确认。

## P4 仅录入内容即可注册同类短句

沿用 `Phrase → Sequence/Event → Player/Pcm + 指板/TAB`。`Phrases.all` 现含 S01 和原创 M01；S01 保留原来的 16 个八分音符、4 个和弦分段、音高和延响。M01 为一小节四分音符 C3–D3–E3–C3，没有和弦分段，属于原创接口验证小句，不冒充歌曲素材。

和弦分段允许为空。空分段时用实际音位显示当前／下一音，绘制单音指板，复用播放器与 TAB；没有旧和弦名、强制取 `sections[0]` 或对零取模。短句标题、类别、来源、段落、条件、技巧、难度与原速来自数据，练习 BPM 仍是独立设置。撤提示同时隐藏单音位和当前／下一弦品提示。

`validatePhrases` 在注册时校验 ID 唯一、必需元数据、标准调弦／无夹条件、音符弦品、事件连续覆盖、弦号不重复、现有 TAB 的八分及更长时值、扫弦方向、分段顺序和事件起点、和弦引用及对应音位。错误包含素材 ID、事件或分段序号。新增同类素材只需构造 `Phrase` 并加入 `Phrases.all`；无需改播放器或 TAB 核心。

当前事件仍不能表达十六分、滑音、击勾弦等新技巧。特殊调弦和变调夹条件会在注册时被拒绝；不能通过改一行条件文字改变音高。具体新素材需要这些能力时再扩展模型，没有预建运行时 GP 解析、通用编辑器、在线曲库、JSON 内容框架或新数据库。
