# V4 预备拍、入拍强音与重新开始 · v112

基线：`codex/fix-cursor-jitter-20261024` 的 `69762ce`。版本为 `1.4.2 / 112`；交付 standalone 变体，应用 ID 延续 `com.a3322505a.guitarlearning.standalone`，与原正式版并存，沿用 v111 独立版签名。

## 行为

- 预备拍与【节拍】开关解耦，按选段起点拍号倒数一小节。4/4 四下、3/4 三下、5/4 五下、6/8 六个八分音符单位；沿用引擎的播放速度与时间轴。
- 预备拍为原基准的 70%，正式起点单次强音为 140%，之后普通拍为 100%。【节拍】关闭时，保留预备拍和入拍强音，之后静音。
- 进度条右侧增加 48dp 的 ↺，无障碍名称“重新开始”，测试标签 `restart-button`。底部仍为 BPM / 播放 / 循环 / 节拍四个主要按钮。
- 重新开始回当前选段起点并完整倒数，保留当前速度、选段、循环、混音、光标偏移。倒数中暂停再继续会重新倒数；正式播放暂停再继续不倒数。自动循环不重新倒数或重新加重首拍。
- 加载及 MIDI 尚未准备好时禁止重开。异步启动用 epoch 丢弃过期回调，准备阶段不接受旧 stop 状态覆盖。

## 1.8.4 局部适配

`EntryBeat184.kt` 仅拦截原合成器 worker 的节拍事件派发，原有 sequencer、TinySoundFont、输出设备、音色和轨道均保留。普通节拍事件的固定力度点击被等价 NoteOff / NoteOn 替代，使用原专属节拍通道、同一个 MetronomeKey 和原事件时间，不叠加第二下。原节拍事件保留为无声遥测。

TSF 的力度到振幅是线性的。普通力度 90、首拍 126，正式通道音量补偿 95/90，维持之前 95 力度的普通响度；最大通道增益约 0.988，力度不超过 127。预备拍仍使用原生 countInVolume = 基准 × 0.7。单次首拍只在显式起播时重新启用，循环不重新启用。

弱起或 grace 偏移没有原生节拍事件时，只在同一引擎事件列表内补一个精确起点点击。使用请求的起点和 MIDI tickShift，不能使用会取整并加一的 tickPosition getter，避免双击。起点的拍号和 MIDI tempo 被显式提供给原生预备拍，修正 seek 恰好位于拍号/速度变更时尚未处理该位置元事件的问题。

alphaTab 没有公开首拍力度接口，本适配固定依赖 1.8.4 的内部结构；访问范围集中在一个文件，升级 alphaTab 或 Kotlin 后必须重跑真实 worker 与 PCM 测试。没有 fork 引擎、修改依赖、修改曲包或额外音频时钟。显示层偏移与光标动画保持原实现。

## 验证

- `EntryBeat184Test`：真实 1.8.4 MIDI → sequencer → TSF → PCM，覆盖 4/4、3/4、5/4、6/8 与 0.5× / 2×；检查每次声响间隔（3.5ms 容差）、首拍/预备拍振幅比约 2、普通响度保持、关闭常规节拍、单次首拍、循环不重复首拍、变拍号起点和非网格弱起。实际 Android worker 的绑定处理器解析也有测试。
- `StageTransportTest`：360dp 手机布局，↺ 的 48dp 点击区域及无障碍说明、四主键可见、准备时禁用。
- 构建与完整 CI 结果以本分支对应的 `Android core / verify` 为准；签名校验、ZIP 对齐、Manifest 检查不代替实体设备安装与听感验收。

## 真机待验收

实体手机/平板的音频缓冲延迟、蓝牙延迟及实际响度感受仍需装包确认。重点检查 4/4 60 BPM、首小节休止、快速重开、倒数中暂停/恢复、正式播放暂停/恢复，以及横屏谱面比例。
