## P1：冻结共同契约

**依赖**：P0。**主要新增**：`contracts/song-package/v1/`，两端验证骨架。

交付：

- 规范、五类 JSON 的完整 JSON Schema、字段默认值/未知字段处理、ID与引用规则、能力清单、资源 limits、错误码及其 JSON pointer/sourceRef 定位。
- 领域类型定义与 invariants：Q、Meter/Measure、Track/Voice/Event/Note、Relation/Tuplet、Tempo/Swing、Form、PracticeSpec、PerformancePlan/Visit、PracticeKey。
- 一个可独立理解的原创最小有效包，及覆盖复拍、多声部/连音、反复、变速/奏法的独立小样本；另有相应无效样本。此时可称契约样本，尚不能声称能在 App 导入。
- 时间线、速度倍率/固定模式、进入/退出策略、未知语义、conditional 来源假设的确切语义，不留给各消费者自行猜。
- 外部和 Kotlin 的同一正反例集；格式解析、语义校验、能力推导的职责明确。

**退出条件**：不依赖歌曲名称即可完整表达需求样本；双方对有效/无效结构和基础语义给出一致判定；任何暂不能表达的需求有明确契约补项，不能带缺口进入生产协议。

## P2：精确音乐模型与旧数据适配

**依赖**：P1。**现有入口**：`Sequence.kt`、`Expression.kt`、`Music.kt`、`Phrases.kt`。

- 实现 Q 精确运算与溢出检查；Meter/actualDuration/分组；通用书写值、附点、N:M/嵌套/跨小节连音。
- 实现稳定 note/event ID、多声部覆盖、同弦冲突检查、轨道调弦/整夹和实音校验、包内和声/指法。
- 实现 LegacySequenceAdapter：旧12/24 tick精确转换，现有连奏/let-ring/力度/padding语义保持；旧代码可暂时继续生成 Sequence，但消费者逐步统一。
- 拆分结构校验与当前 `validatePhrases` 的单流/全局和弦规则，不删除必要检查。显式休止/整小节休止/未知来源不能混为一类。

**验证**：复拍、弱起、五/七连音、同拍双声部、Drop D/夹、非法同弦/关系；旧曲标准化投影逐项一致。

**退出条件**：模型无损覆盖契约；任何新样本不需要增加 PPQ 档位、歌曲 if 分支或改成单声部。

## P3：曲序、速度与会话编译

**依赖**：P2。**现有入口**：`Session`、`BarRange`、`Cursor`、SevenBlocks 曲序与 Kafka 教学组合逻辑。

- 实现有界 Form 编译、visit 身份、房子/回跳/经过条件；编译时检测死循环、引用缺失与超预算。
- 实现 PracticeSpec 的选段/拼接/padding、曲序策略、状态进入与结束，保留 sourceRefs 和来源未核说明。
- 实现 TempoMap 正反时间映射、渐变/速度单位、练习倍率/固定速度、swing 规则和预备拍。
- Session 消费不可变计划；Cursor 支持多声部 active notes、source measure/visit/loop 区分，继续按当前经过的小节恢复。

**验证**：用人工列出的 visit 序列和解析计算的时间点断言；帧正反映射关键点误差≤1帧，多轮边界不累积；反复第二次经过的暂停/选区定位正确。

**退出条件**：声音/节拍/光标可以只依赖同一个时间映射；没有第二个展开器或固定 BPM 快捷路径。

## P4：接入现有播放器与显示

**依赖**：P3。**现有入口**：`Player.kt/Pcm.kt/PlaybackSink.kt/TabNotation.kt/Tablature.kt/PracticeApp.kt` 及显示状态。

- Player 保留音频焦点、generation取消、pause/resume/restart/stop语义；设备帧扩展为单调 Long，变速从编译映射读取。
- PCM 复用 Sampler/音源与包络，按计划处理多声部、调弦、持续音和选区边界；建立活动音符索引和受限缓存，避免整曲/每轮预渲染。
- TAB 复用绘制基础和分行，按声部/小节局部 beatGroups 排列符干/符杠/休止/连音/连线；同拍多事件不触发间距除零。为复杂谱复用横向滚动或合理宽度，不能靠缩小到看不清解决重叠。
- 指板消费选定主轨的 active notes；多条连奏关系、同时延音的音位不能仅取 firstOrNull。点音和显示音名使用该轨调弦/capo。
- 让所有旧内容、音阶和和弦练习也进入同一运行时链路；原默认目录/导航/平板和底栏样式保持。

**退出条件**：旧内容直接相关测试通过；原创复杂谱可以显示和播放。渲染截图需实际审看，高/低声部、连音/变拍至少一组；自动播放不是试听/实弹验收。
