基线为 `7411a8240172936b4373ba300940afc68c31897d`；按用户提供的三份替换文件、《UIUX01.md》和《高频播放游标内核接口.md》完成工程接线。应用 ID 和长期签名保持；正式版本为 `98 / 4.3.0-local50-linked`。

按执行方案末尾“不覆盖升级”的要求，实际交付另用 `-PtabletReview=true` 构建并装验收包：应用 ID 为 `com.a3322505a.guitarlearning.tablet98`，显示名“吉他练习·联动验收”，版本名带 `-review`。它使用相同界面、音乐代码、资源和长期签名，但有独立数据目录，不覆盖原 App。默认不加该参数的正式包继续使用原 ID；两者分别记录源码与 APK 哈希。

## 使用

- 顶部内容胶囊打开音阶、和弦、歌曲与短句。歌曲/和弦卡片选中即关闭；音阶参数在内容面板调整。宽窗口内容卡片按最小可读宽度排成至多六列。
- 偏好独立提供跟练、声音和外观；底部保留速度、示范和跟练操作。GP 导入页面、Manifest 入口和专用曲库持久化已移出正式源码。曲包管理、审核曲包、alphaTab 共享解析和历史用户文件保留。
- 歌曲默认联动舞台；指板与纯谱切换保留同一个原生谱面挂载点，按真实可见尺寸调整高度。窗口过矮时优先显示谱面。切换视图不强制旋屏。
- 点谱默认无声；上/下一步按主练轨同起点事件组移动，含休止及同音重拨。滚动、长按和多指操作不定位。听当前音复用现有试听。
- 普通暂停后“继续”接原位置并关闭再次预备；点谱或步进后“从本小节练”回到该经过的有效小节头，固定预备后起练。原选区、速度和次数保留，后续循环仍回到原选区头；“本轮重来”从原选区头开始。延音入口沿用原有拒绝提示。
- 指板只显示当前小节上下文、持续音、当前焦点与下一有效起点。静音保留教学音位；停止、结束、出错和预备不显示实时演奏高亮。窗口含当前与下一目标并有移窗迟滞；单音对应明确时使用独立虚线移动提示。
- 指板标注支持审核指法、实际音名，以及明确根音下的级数。标注偏好与原来的隐藏提示键分离；空弦 O、死音 X、未知指法回退音名。

## 接口和数据边界

`PracticeFocusIndex` 持有不可变 `PerformancePlan`，按精确 Q 分组并保留 PlanEvent/PlanNote、声部及经过身份；SDK 命中通过展开后小节和 beat.displayStart 回到同一索引。SDK 定位 tick 取该拍 playbackStart；会话 tick 显式按 quarter 换算。普通继续和拆解起练分别实现，选择本身不重载 MIDI。异步准备按内容 generation 失效，排队回调按操作 epoch 失效。

alphaTab 1.8.4 Android 在关闭默认交互时，确认单击仍发出 beatMouseDown，但不发出 beatMouseUp。原生外层容器仅观察手势，过滤拖动、长按和多指；SDK 的命中、滚动、播放光标及动画仍由 SDK 提供。没有第二个时钟。加载、渲染、挂载和 MIDI 次数在 `AlphaPractice` 日志中记录，供等宽收放检查。

新增 `practice.noteFingerings` 和能力 `teaching.note-fingering.v1`，字段为 sourceNoteId、可空 finger（1–4）、审核 source、可选 occurrence。教学数据属于练习，源谱音符保持不变。具体经过覆盖通用指法，显式 null 表示未知；没有逐音数据时，仅匹配当前实际 voicing 的弦品、轨道和指法。公共 schema、App 副本、Python 校验、Kotlin 解码/校验、PerformancePlan 和 SDK leftHandFinger 同步。extensions 仍是纯文本。

新增 `example.note-fingering` 修订 2 协议样例，来源为原有原创 simple fixture；score.json 字节保持，practices/review/manifest 的哈希重新绑定。现有歌曲未凭品位或音高补写指法。旧曲包继续读取；生产工具对不支持新能力的旧 capabilities 明确拒绝。已发布的旧 App 不被修改，它们的封闭 schema 也会拒绝新字段。
