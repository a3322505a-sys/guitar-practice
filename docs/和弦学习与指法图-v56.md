# v56 和弦学习与指法图修正

日期：2026-10-11。目标工程为 `guitar-practice`。版本 `3.3.1-local08 / versionCode 56`，包名 `com.a3322505a.guitarlearning`，沿用既有长期签名。

v55 把一级「和弦」替换为「短句」，并把逐弦检查藏在更多中，偏离了用户要求的基础学习顺序。本版恢复和弦学习为主入口，把短句放回次级应用；同时解决指法图随容器宽度横向拉伸的问题。

## 当前入口与学习顺序

一级导航为「音阶／和弦」。进入和弦后默认「和弦学习」，直接选择 C、Am、G、Em、D、Dm、E、A、Gsus2、Asus4(no5)、Bm7(no5)、D/F♯ 十二个指法。

基础学习按下面顺序进行：

1. 看当前指法的根音、三音／挂留音、五音／七音及实际音名。
2. 点指法图中的有效音位，试听单音并查看弦品、音高和角色。
3. 用「听和弦」同时试听当前指法的全部有效弦。
4. 用「听示范／开始跟练」逐根弹有效弦，每弦一拍，检查闷音或杂音。
5. 切到页内「短句应用」，将所学和弦放入无夹《嘘月》S01 的分解伴奏。

切回基础学习保留已选和弦，短句也保留已选素材。切换实际内容结束旧序列；点击当前入口、打开设置和切换指板／TAB 保留播放。速度、循环与声音仍由原来的「速度与播放」入口控制。

组成音直接来自 `Chord.positions`，整和弦试听使用同一组位置。Asus4(no5) 不补 E，Bm7(no5) 不补 F♯；D/F♯ 仍以 F♯ 为最低音。禁弹弦不产生音位，也不能点击误触邻弦。撤提示同时隐藏组成音说明。

## 指法图

六根弦为竖线、四个品位为横格，四品网格宽高相等，图形居中。弦距、品距、音位圆点使用同一个缩放比例，宽卡片只增加两侧留白。品号在左边，底部依次为实际音名和 6→1 弦号。

金色为根音、绿色为其他和弦音、粉色为当前音。O 空弦也保留颜色，X 为禁弹弦；按弦圆点内 1—4 为手指。取消了旧图中仅给少数指法添加、没有统一说明的紫色描边；播放中的当前音描边保留。

绘制和点击共用 `ChordGeometry`。点击先确定弦号，再判断该弦实际音位距离；小图中触摸 X 弦不会因为触摸范围较大而试听旁边的有效弦。小屏将次级导航与设置按钮合在一行，为图下的音名和弦号留出空间。

## 与参考项目的关系

已读取 [FretFlow / fretboard-app 的 README](https://github.com/iecg/fretboard-app/blob/main/README.md)。它以指板上的音阶、和弦音、指法和声音探索为核心，并进一步提供进行与声部连接等练习。本地学习方向据此调整为先认识和弦音、看懂位置、听出声音，再进入短句应用。

本轮独立调整现有 Kotlin / Compose 工程，没有复制其源码。本版落实的是基础和弦探索和入口层级；全指板和弦音叠加、任意根音与性质选择、更多指法以及声部连接提示尚未实现，后续应沿同一方向增量补充。

原音阶精简行为与 v55 无夹伴奏保留。源谱真实性仍不作为门槛；带变调夹内容与单音素材继续延期，不扩展运行时曲谱导入、账号、评分或课程系统。
