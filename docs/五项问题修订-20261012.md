## 真机复核步骤

设备连接后，记录 Android 版本、导航方式、切口类型和屏幕缩放，使用本轮源码构建递增版本的同签名包后再做覆盖升级。

1. 指板冷启动；连续切换 TAB / 指板，两个横屏方向，后台返回与设置打开 / 完成 / 返回；从顶部临时呼出系统栏。录屏检查无应用主动 show/hide 竞争、持续偏移、谱面裁切与底栏遮挡，返回和系统手势正常。
2. 手机横屏 / 平板查看 T01、R02、PM01、SL01、K265 及长音和弦；检查六弦、数字、休止、双符梁、数字 3、连奏与表达记号。短窗口可纵向浏览完整谱行。
3. 逐音播放 M01、R02、PM01、S01，比较主卡 / 指板 / 控制的位置，核对当前、下一、休止、死音和必要奏法；撤提示后不泄露音位与奏法。
4. 音阶三度跳进一八度、每拍 3 音、60 BPM：完整 4/4 小节无休止，共 12 次起音；核对暂停 / 继续、预备、BPM 与循环。主音与八度及 sol 整型往返另检尾组补休止和下一轮起点。

窗口策略参考 [Android 官方沉浸式文档](https://developer.android.com/develop/ui/views/layout/immersive)。本轮 API 28 兼容路径通过自动检查，不能替代 Android 16 等实机窗口验收。
