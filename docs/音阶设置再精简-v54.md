## 当前行为

六类音阶练习及其音乐路线保留：

| 练习 | 保留的思路 |
| --- | --- |
| 音阶往返 | 一轮内低到高再回到低，转折音不重复，包含两个方向 |
| 三度跳进 | 调内 1–3、2–4、3–5……，保持大小三度的差别 |
| 指型连接 | 经共享主音跨入下一指型，保留实际连接与不可用提示 |
| 主音与八度 | 找出主音的不同位置，依次弹响 |
| 三音模进 | 1–2–3、2–3–4、3–4–5…… |
| 换起点 | 从所选级数开始，沿原路线循环并返回起点 |

前三项仍是常用练法，后三项在「更多练法」。只保留音域「一八度／整型音域」、节奏「每拍1音／每拍2音」这两组简单选项，分别对应局部／完整指型练习及两种细分。换起点直接显示起点级数；不适用音域的练法继续隐藏音域控件。

移除「范围与显示」及「更多练习选项」入口、逐弦范围、反向设置、音名／级数选择。固定允许全六弦，由所选指型、音域及练法确定实际路线，显示音名，使用各练法的默认顺序。恢复旧状态时，将已移除的弦范围与反向值归为默认，避免隐藏参数继续限制练习；旧练法 ordinal、调性、指型、音域、节奏和起点级数保留。已有显示偏好文件没有清空。

练习设置／速度与播放两个入口、点音、示范、跟练、撤提示、指板／TAB 切换与播放生命周期保持。la 三弦 4 品 B 及伸指提示保留；和弦和歌曲短句的改动仍留待后续。
