# V3.1 原生和弦/音阶词典、四大教学模块与「每日练习」曲包整合实施规范

> **目标：底层完整覆盖、教学渐进呈现、曲包开箱即练。**  
---

## 0. 决策与边界（优先级最高）
1. **一次实现完整的基础数据能力**：不得只把本文列出的几个例子硬编码进界面；音程规则覆盖全部 12 个主音，常用和弦/音阶及多配法形成可查询的原生数据。
2. **词典与教材分离**：词典描述“真实是什么”；教材决定“现在教哪一种、练哪一小段”。不要把替代和弦误报成原和弦，也不要把全量词典一次性展示给新手。
3. **App 是练习执行器**：进 App 直接选曲包/卡片/版本开始练，支持自由循环和段落衔接。
4. **曲包离线可用、预处理优先**：Agent 在外部整理、校验、编译曲包；运行时直接读取确定的数据，不强制 App 临时猜和弦名、指法或段落。

## 1. 目标数据模型与基础规则

### 1.1 和弦实体、配法与替代关系必须拆分

- **ChordDefinition（和弦定义）**：根音、性质、理论构成音、音程集合、准确记谱拼写、允许的省略音及别名。
- **ChordVoicing（实体配法）**：标准调弦下 6→1 弦的 `fret[6]`、逐弦实际音名/八度、最低发声低音、左手指法、横按范围、空弦/O、静音/X、按法名称、难度、适用上下文。
- **ChordSubstitution（替代关系）**：与目标和弦的关系是①完全相同的和弦不同配法、②扩展/色彩替代、③改变和弦性质的条件性替代；不得混淆。
- **PracticeEvent（谱面事件）**：所弹音/和弦、弦品、开始时间与时值、轨道、强弱、技巧、建议指法及音符关联的真实和弦 ID。
- **Phrase/Section/Version（乐句/段落/版本）**：精确小节与拍点边界、轨道归属、重复/衔接区间、练前热身 ID、默认速度、变体关联和统一的时间基准。

### 1.2 六弦/左手表示协议

- 固定排列 **6→1 弦：E2、A2、D3、G3、B3、E4**，和弦编码示例 `x32010`。
- 指板落点 `0` = 空弦；`X` = **不发声的弦**；正整数 = 品位；左手 `1/2/3/4` = 食/中/无名/小指；`T` = 拇指按弦。
- **横按 Barre 独立记录**：手指、品位、覆盖弦区间及真实压弦范围。不能把跨越空弦的错误大横按登记为合法。
- **掌闷音 PM ≠ 静音弦 X**：前者是有音高、缩短延音的演奏技巧；后者不得作为正常发声音符。
- 显示字段分别为：**记谱和弦名、实际音名/八度、实际最低低音、和弦构成音、配法/别名**。升降号采用正确的调性拼写，底层音高可另存 pitch class/MIDI 值。
- 移调夹记录 `capoFret`、相对形状及**实际发声**音高与和弦名；不要把指型名直接充当实音名。

### 1.3 可复核的数据例子（不能替代全量词典）

```yaml
voicingId: CSharpMinor7_OpenTop_01
chord: C#m7
frets_6_to_1: [X, 4, 6, 6, 0, 0]
fingers_6_to_1: [X, 1, 3, 4, 0, 0]
barres: []
sounding_notes_6_to_1: [X, C#3, G#3, C#4, B3, E4]
bass: C#3
chord_tones: [C#, E, G#, B]
voicing_label: 开放高音弦 C#m7
```

此例为**真正的** `C#m7(x46600)`。之前拟议的 `C#m7(x46650)` 实际只有 C#、E、G#，是 **C#m**，缺少 B，不能继续作为 C#m7 收录。

### 1.4 必须纠正或精确标注的既有示例

| 原提案 | 真实结果 | V3.1 处理 |
|---|---|---|
| `C#m7(x46650)` | C#m（缺小七度 B） | 从 C#m7 移除；改收 `C#m7(x46600)`，原配法可作为 C#m 的色彩按法 |
| `F#m7(244200)` | F#m7(add11)，同时含 B | 以 **F#m7(add11)** 入词典，允许作为 F#m7 的色彩替代；不可假装与普通 F#m7 完全相同 |
| `Bm(xx4432)` | Bm/F#（最低音 F#3） | 可挂在 Bm 家族，但配法须明示斜杠低音 `Bm/F#` |
| `Bb(xx3331)` | Bb/F（最低音 F3） | 可挂在 Bb 家族，但配法须明示斜杠低音 `Bb/F` |
| `Fmaj7(xx3210)` | Fmaj7，低音 F3 | 合法、适合简化练习；不得称低音为 F2 |
| `Fmaj7(133210)` | Fmaj7，低音 F2 | 可作为含拇指 `T` 的配法，但不得强制新手学习 |
| `F(xx3211)` | F | 保留局部横按/小横按版本 |
| `Bm7(no5)(x2023x)` | B、D、A（Bm7 省五度） | 保留，名称明确 `no5` |
| `Bm7(x24232)` | Bm7 | 保留，但不能一概宣称比 Bm 简单 |
| `Bsus2(x24422)` | Bsus2 | 保留，属改变和弦性质的替代；横按难度可能仍高 |
| `B7(x21202)` | B7 | 保留，属不同和声性质的条件替代 |
| `G6(320000)` | G6（含 G、B、D、E） | 保留 |
| `Am5` | 通常应写 A5 | Power Chord 不含三音，无大小调性质 |

> 注：以上“同一和弦家族”和“精确配法名称”可并存；严格字段不能因为常用简写而失去低音/构成音信息。

## 2. 全量常用和弦词典

**目标**：至少覆盖下列 6 大类、60+ 核心和弦及其常用配法；通过统一音程规则支持 12 主音移调，不能将表中少数指型当作“全量已完成”。

### 2.1 必须收录的和弦范围

1. **开放大小三和弦**：`C D E G A`；`Am Dm Em`，每个含开放常见配法及可教学的高把位配法。`F/B/Fm/Bm` 等通过横按组、可移动配法组覆盖。
2. **七和弦**：
   - Maj7：`Cmaj7 Dmaj7 Emaj7 Fmaj7 Gmaj7 Amaj7 Bbmaj7`。
   - m7：`Am7 Bm7 Cm7 Dm7 Em7 Fm7 F#m7 G#m7 C#m7`。
   - 属7：`C7 D7 E7 G7 A7 B7 F#7`。
3. **E/A 型可移动横按与开放高音弦色彩**：6 弦根音、5 弦根音的大/小三、大/小七和弦，重点 `F Fm B Bm Bb Bbm F# F#m C#m G#m`；加收 `C#m7(x46600)`、`F#m7(add11)(244200)`、`Asus2(x02200)`、`Bsus4(x24400)`、`Eadd9`（候选 `022102`，校验后入库）。
4. **挂留/加音/斜杠低音**：`Dsus4 Dsus2 Esus4 Asus4 Asus2 Gsus4 Gsus2 Cadd9 Dadd9 Gadd9 Aadd9`；`C/G C/E G/B D/F# Am/G E/G# F/G`。其中 `Am/G`、`F/G` 属**指定非和弦低音**，不能统称为三和弦转位。
5. **Power Chord、八度、减与半减和弦**：12 半音根音 `E5 F5 F#5 G5 G#5 A5 Bb5 B5 C5 C#5 D5 D#5` 的 6 弦/5 弦根音可移动双音版和三音（根音+五度+八度）版，明确非弹奏弦 X；收 `G#dim7 D#dim7 Bm7b5 F#m7b5`，严格区分 dim、dim7、m7b5 的音程。
6. **新手减负与色彩替代**：保留 F、Bm、B、F#m、C#m、Bb 的上述各候选方案；分别归类为“同和弦不同配法”“色彩替代”“条件性替代”，可在曲包中切换，但不能隐去和弦名变化。

### 2.2 生成、收录与准确性

- 音程公式驱动 12 主音和弦定义；**人工维护/程序校验具体可按的指型**，禁止只做半音平移而忽略开放弦、横按与真实低音。
- 每个收录配法都要从六弦实音**反算**根音、三度、五度、七度、扩展音与最低音；必要时写 `no5/add11` 或斜杠低音。
- 允许省五度等真实音乐实践，但必须明确省略项；**主和弦名与配法实际构成不能矛盾**。
- `X5`、八度音型支持明确需静音的中间弦和其余邻弦；八度音型不应误判为 Power Chord。
- 每个和弦至少有适用该条目的主要规范配法；高频横按和弦提供可用的非大横按/简化方案（如存在），没有可行同性质简化配法时不得伪造。

## 3. 全调式音阶与位置库

### 3.1 理论与数据覆盖

- 全 12 主音：自然大调、自然小调、大调五声、小调五声、布鲁斯音阶（至少 **12 × 5 = 60** 套基本音高集合）。
- 维护调式音程、主音、实际音名拼写、每音级数、指板全部落点及其八度信息。
- 独立维护经验证的开放把位：`C/Am`、`G/Em`、`D/Bm`、`A/F#m`、`E/C#m`；关系大小调可共用音高，但主音、级数、解决方向不能合并。
- **五声音阶**以 5 个标准封闭 Box 为主线；**七声音阶**用 5 个 CAGED 关联位置作为本版主体系。如果将来增加 3NPS（每弦三音），应作为独立的 7 位置体系，不能混叫相同 Box。
- 封闭指型通过根音/基准位置映射到 12 主音，保证跨指型滑音的起点、终点和把位转移合理；开放指型不能无条件整体平移。

### 3.2 五类指板视图定义

| 视图 | 数据语义 |
|---|---|
| `FULL` | 显示当前选择的完整音阶（自然七声、五声或蓝调六声） |
| `PENTATONIC` | 显示与当前主音/大小调性质关联的五声音阶骨架；蓝调视图可去除蓝音 |
| `CHORD_TONES` | **按当前真实和弦事件**显示构成音，不限制为当前调式内的音 |
| `ROOTS` | 可明确显示“当前调式主音”或“当前和弦根音”，UI 不允许歧义 |
| `HIDDEN` | 不显示音阶提示 |

- 左手指法为**建议映射**，允许根据段落上下文选择不同指型；Box 切换箭头仅在**把位/Box 变化**时出现，不用单音箭头制造错误教学暗示。
- 和弦音视图与和弦时间轴严格同步；高亮能区分根音、三度、五度、七度（扩展音可额外标注），不把切换之前的和弦靶心滞留到下一小节。

## 4. 四大原生教学模块

### A. 基础启蒙

- `FB-1`：单弦交替拨弦与强弱拍，先准确后提速。
- `FB-2`：保留指/手指独立性；只在**不妨碍下一音**时保留，不强制全程硬压四指。
- `FB-3`：单八度三音动机、问答句、移位模进；此处“三音”指**三音动机**，不等于七声音阶 3NPS 指型。
- 扩展：跨弦、切音、基础滑音、击勾弦及节奏变化，遵守循序渐进。

### B. 和弦教学

- 开放大/小三 → 高频两和弦切换 → 简单 Power Chord 与基本律动 → 局部横按/完整横按 → 七和弦/挂留/加音 → 常用和声进行与转位。
- 每一对和弦的“保留指”“引导指”“抬起重新落指”必须绑定**两套具体配法**，不能只依据和弦名称猜测。
- 示例进行（以 C 大调为例）：
  - `1–5–6–3–4–1–4–5` = `C–G–Am–Em–F–C–F–G`
  - `4–5–3–6–2–5–1` = `F–G–Em–Am–Dm–G–C`
  - J-Rock 常见 `4–5–6` = `F–G–Am`
- 引导学生听辨和声作用，不用“只记形状”代替理解。

### C. 音阶教学

- 单八度微单元 → 五声骨架 → 七声补全 → 和弦音靶心 → Box 间滑音串联；优先 `C/Am G/Em D/Bm E/C#m`。
- 每个阶段至少提供**可听出问答/落点**的短句，不得全部写成无音乐性的纯上下行音阶。
- 逐步加入三/四音模进、跨弦、滑音、节奏错位、短句收尾；不要要求新手在同一个版本内掌握全部技巧。

### D. 综合应用与示范曲包

- 和弦加花：`C→Cadd9→C`；`D→Dsus4→D→Dsus2`。
- 低音线：`G→D/F#→Em→C` 只能称**前三个低音 G2→F#2→E2 下行、随后转到 C**；`C→G/B→Am→Am/G→Fmaj7` 须根据实际配法/八度判定是否连续下行。
- Capo：同时显示形状、实际和弦名、实际发声音名。
- J-Rock：Power Chord、掌闷音、八度 Riff、小调五声 Solo。
- 制作 **2–3 套 V3.1 满配示范曲包**，具不同教学版本、开放衔接循环、独立领奏/伴奏双轨、Solo 乐句边界、关联热身 ID。
- P5 领奏渐隐可提供 `100% / 30% / 0%` 手动档位（或用户明确选择的循环预设），不做音准判分；倒序接龙指**倒序累加乐句练习范围**，不是反向播放音频或把音符倒着弹。

## 5. 首套示范曲包：《每日练习 · 同调渐进小套曲》

> “每日练习”只是**曲包名**，不是每日签到或任务。四张卡片自由单练、选版本、调速、循环，也可按顺序连接成微缩小曲。  
> **统一音乐语境：4/4 拍，C 大调 / A 自然小调，共 36 小节（8+8+8+12）。**  
> 单卡片推荐速度与连播速度分别配置；连播可采用统一约 80–85 BPM 的用户所选速度，**不自动阶梯变速**。

| 卡片 | 模块 | 标题 | 长度 | 推荐速度 | 基础版 / 进阶版 |
|---|---|---:|---:|---:|---|
| DP-01 | 基础启蒙 | 指尖唤醒：三音模进与跨弦问答 | 8 小节 | 75–90 BPM | 顺阶三音、交替拨弦 / 跨弦、局部手指控制 |
| DP-02 | 和弦教学 | 黄金四和弦：低音连线与色彩加花 | 8 小节 | 约 80 BPM | 简化扫弦 / 分解与加花（也可提供不同伴奏版本） |
| DP-03 | 音阶教学 | 五声会说话：和弦音靶心 Solo | 8 小节 | 约 85 BPM | 开放把位问答 / 滑音入 Box 1、击勾与倒序接龙 |
| DP-04 | 综合应用 | J-Rock 引擎：闷音推进与副歌爆发 | 12 小节 | 入门 80–90、进阶 105–120 BPM | 慢速简化 / 动态变化与八度 Riff |

### 5.1 DP-01｜指尖唤醒（8 小节）

**目标**：右手交替拨弦、左手准确落点、跨弦同步、短句呼应。不是全程纯半音爬格子，更不是在音乐性练习中强制“所有四指不得抬起”。

- 第 1–4 小节围绕 `C–D–E`、`D–E–F`、`E–F–G`、`G–A–G` 的三音动机展开；第 5–7 小节下行呼应，兼顾 3/4 弦跨弦；第 8 小节以 **C3（5 弦 3 品）全音符**收束。
- 需要纠正原文节奏不自洽的问题：**每小节前 3 拍 = 6 个八分音符；第 4 拍 = 1 个四分音符**。可将当小节三音动机重复一遍形成 6 音，再用第 7 音作四分收束；不能把“3 个八分音符”写成“前三拍”。
- C4 的实际位置为 **2 弦 1 品**；第 7 小节所谓 `1-2-3-1` 必须明确到底是**手指编号**还是**音阶级数**，编译时不能省略。
- `FULL / ROOTS` 视图可选；只提供清晰的主音落点，不强制显示满屏手指提示。
- 需由 Agent 落地为**逐音、逐弦、逐时值的 8 小节谱面**，不是只写动机文字。

### 5.2 DP-02｜黄金四和弦（8 小节）

**目标**：切换真实轨迹、部分保留指、低音变化、挂留/加音。**不得宣称所有和弦都能一直保持 2 弦 1 品食指。**

| 小节 | 和弦/动机 | 具体配法与教学点 |
|---|---|---|
| 1 | C | `x32010` |
| 2 | G/B | `x20003` 或 `x20033`（均须按实音校验） |
| 3 | Am7 | `x02010` |
| 4 | Fmaj7 | `xx3210`，最低音 **F3** |
| 5 | C→Cadd9→C | `x32010 → x32030 → x32010`，局部增加/释放高音弦 3 品 |
| 6 | G→Gsus4→G | 如 `3x0003 → 3x0013 → 3x0003`（G→Gsus4 不得残留 B 三度） |
| 7 | Am→Asus2→Am | `x02210 → x02200 → x02210` |
| 8 | Fmaj7 | `xx3210`，延音收束 |

**重点更正：**

- 第 1–4 小节低音为 **C3→B2→A2→F3**，只在前三个和弦下降，**F3 并非进一步下行到 F2**。因此教学文案改为“前三和弦级进下行、Fmaj7 收束”。若未来专门练 `C3→B2→A2→F2`，需另设带 F2 的可行配法，不能冒用 `xx3210`。
- 2 弦 1 品的 C4 可以在 **C、Am7、Fmaj7** 三个配法中出现，但切到上述 `G/B` 需要释放/调整；前瞻指板只提示**真实可保留**的手指。
- 简化扫弦节奏可用 `下｜下｜下上｜下上`（第 1、2 拍四分，第 3、4 拍八分）。分解版按实际发声弦编排：对 C/G/B/Am7 可用 `5-3-2-3-1-3-2-3`；对 `Fmaj7(xx3210)` 改为 `4-3-2-3-1-3-2-3`，**绝不能去弹其 X 标记的 5 弦**。
- 5–7 小节加花必须给精确**起止拍点**，例如第 1–2 拍主和弦、第 3 拍加花、第 4 拍回主和弦；不同版本可调整具体扫弦音符，但必须保持每小节完整 4 拍。
- 这里是原创练习，只用“简化扫弦版/分解加花版/律动版”，**不使用“原谱分解版”**。

### 5.3 DP-03｜五声会说话（8 小节，领奏/伴奏双轨）

**固定独立伴奏时间轴**：`C(x32010) → G/B(x20003) → Am7(x02010) → Fmaj7(xx3210)` ×2，每小节一和弦。该伴奏和 DP-02 **前四小节**和声一致，但不等于照搬 DP-02 后四小节的加花和弦；独立卡片必须自洽。

- **第 1 小节 C**：重拍旋律落 E（大三度）。
- **第 2 小节 G/B**：重拍落 D（G 和弦的五度）。
- **第 3 小节 Am7**：重拍落 C（Am 的小三度）。
- **第 4 小节 Fmaj7**：3 弦 2 品 **A3** → 3 弦 5 品 **C4** 的无名指滑音，落点 C 是 Fmaj7 五度；准备进入 A 小调五声第 5 品 Box 1。
- **第 5–8 小节**：5–8 品 A 小调五声 Box 1 的问答、击勾与短句收束；必须提供具体音符、时值、弦品、乐句边界。
- C 大调/Am 小调五声共用 `{C,D,E,G,A}`；**F** 本身不在该五声音阶里，所以 Fmaj7 的靶心可选 A/C/E，不强行要求 F。`CHORD_TONES` 仍应按和弦显示 F 在指板上的位置（因为其语义是和弦音，不是五声音阶音）。
- 从 3 弦 2 品滑到 5 品后，允许安排**左手位置重整**，不能认为单次滑音已自动形成完整 Box 1 指型；基础版可不跨把位。
- 提供 `100% / 30% / 0%` 领奏参考音量手动选择；渐隐只作用于领奏，不动伴奏。倒序接龙优先练第 7–8 小节，再扩展第 5–8 小节，是**反向扩大乐句窗口**。

### 5.4 DP-04｜J-Rock 引擎（12 小节）

**音乐目标**：4 小节收紧的主歌式驱动 + 4 小节开放的副歌式爆发 + 4 小节八度 Riff 收尾。基础版允许省略繁复技巧，不能强制新手一次学会所有高级动作。

| 段落 | 小节 | 和声与音型 | 规则 |
|---|---|---|---|
| A：Build-up | 1–4 | `F5 → G5 → A5 → C5` | 一小节一和弦，八分音符下拨；8 个八分中**前 5 个 PM、后 3 个放开**，逐事件明确静音/发声 |
| B：Chorus | 5–8 | `Fmaj7 → G6(320000) → Em7 → Am` | 解除 PM、展开扫弦，保持和弦音名正确；基础版可降速、简化扫弦 |
| C：Outro | 9–12 | 八度 Riff：F→G→A→E→A | 5/3 弦双音、4 弦必须静音；为 4 小节写出明确节奏/休止，最后切音收尾 |

- A 段示例合法 Power Chord 配法：`F5(133xxx)`、`G5(355xxx)`、`A5(x022xx)`、`C5(x355xx)`；可替换为按法更连贯的等价配法，但必须记录完整的 X 弦。**统一写 A5，不写 Am5**。
- B 段参考可行配法：`Fmaj7(xx3210)`、`G6(320000)`、`Em7(020000)`、`Am(x02210)`，全部逐弦验算后落谱。
- C 段八度位置：`F=(5弦8品,3弦10品)`、`G=(10,12)`、`A=(12,14)`、`E=(7,9)`；“中间 4 弦 X”必须随音型记录。12 小节总谱不能只给出五个音名，必须写清 9–12 小节各音时值。
- **推荐衔接循环：第 4 小节末 → 第 5 小节首**（PM 解除＋Power Chord 转开放和弦）；其区间以精确拍点存储，可由用户自由开启。
- 入门档默认 **80–90 BPM**，已掌握上述技巧的进阶档 105–120 BPM；没有按表现自动升速或通关机制。

### 5.5 套曲化但不捆绑

- 各卡片独立自洽，有开头、明确的拍数和收尾；一键单练。
- 音高语境一致并不等于**四张卡片使用同一和弦进行**：DP-02/03 为 `C–G/B–Am7–Fmaj7`，DP-04 A 段为 `F5–G5–A5–C5`、B 段为 `Fmaj7–G6–Em7–Am`。若连播，需设置可听起承转合的过渡/收束，不假称完全相同。
- 连播不得私自使用不同 BPM 硬切造成节奏断裂；用户可选统一速度，或使用明确谱面标注的速度变化（不涉及自动能力判断）。
- 在教学版之外可扩展**更音乐性的完整编排版本**，但要复用同一曲包、同一数据模型，不另做平行教学体系。

## 6. 曲包格式与播放器对接

每张卡片至少具有：

- `packId/cardId/versionId`、模块归属、标题、教学目标、推荐速度、拍号、总小节数、难度标签；
- 精确**小节/拍点/时值**的音符事件，不允许只有“第几小节弹哪个和弦”而没有可执行谱面；
- `voicingId` 绑定的和弦事件，手指/Barre/开弦/不弹弦、分解或扫弦的右手目标弦与方向；
- 独立的伴奏与领奏轨，各自的音符、增益、静音/独奏开关；节拍器音量、音乐音量独立调节；
- 乐句与段落边界、跨相邻段循环窗口、领奏渐隐可选档位、倒序接龙乐句序列；
- 关联的热身 `practiceId`，但**不强制先完成热身才能练曲**；
- 默认版与简化/律动版之间有明确映射，时间轴可核对，若修改和声必须更新真实标签和构成音。

**功能分层**：包内仅存已编译的内容、轨道和建议练法；前瞻指板/五类视图/衔接循环/领奏渐隐/倒序接龙是播放器对这些数据的解释与执行。不得把播放逻辑复制进每个包，也不得新增自动评分依赖。

## 7. 自动校验、抽样复核与验收

### 7.1 校验器必须覆盖

1. **和弦名称反算**：用 6 根弦调弦＋品位计算实际音高；检查构成音与 chordSymbol / omissions / additions / slash bass 的一致性。
2. **可行性**：实际发声弦不能标 X；需要拨的弦不能为 X；所有按弦音有有效手指或 Barre/T 信息；没有物理上冲突的横按。
3. **尺度与把位**：12 主音 × 5 类音阶的音程集合正确，开放位置独立验证，五声 Box 与七声 CAGED 关系正确。
4. **事件完整性**：4/4 小节拍数精确；每个版本各轨的 note-on/off、休止、技巧与小节边界合法。
5. **和声同步**：每一时刻 CHORD_TONES 的高亮与伴奏实际和弦对应，不凭当前调式猜测；ROOTS 显示选择明确。
6. **滑音/横按/切换**：落点实际音高、品位/手指/八度准确；只有实际可留的手指才标保留指；跨 Box 箭头仅用于把位切换。
7. **低音线**：低音“上行/下行”根据 MIDI 音高逐个判断，不只比较字母名或级数；检查相对 Capo 与实际低音。
8. **跨版本与曲包衔接**：版本总拍数、伴奏/领奏同步、独立循环、4→5 小节边界与倒序乐句窗口正确。

### 7.2 完成交付标准

- [ ] 12 主音理论词典与指定 60+ 核心和弦覆盖完整，无缺类，常见多配法可查询。
- [ ] 每个配法六弦/O/X、实际音名/八度、构成音、真实低音、1–4/T 指法、Barre 和按法名可用且已验算。
- [ ] 五类音阶覆盖所有 12 主音，开放指型/五声 Box/CAGED 七声数据与视图切换正确。
- [ ] 四大教学模块均有可执行内容，非仅列目录或留下空卡片。
- [ ] 「每日练习」四卡片的 **8+8+8+12 = 36 小节**均有逐音逐拍可播放谱面，基础/进阶等版本齐全。
- [ ] DP-03 双轨、CHORD_TONES 逐和弦靶心、可选渐隐与倒序接龙；DP-04 第 4→5 小节衔接循环可用。
- [ ] 音乐/伴奏和节拍器音量可以分别手动调整；练习自由选择、循环、调速，没有评价和签到机制。
- [ ] 测试与项目关键 CI 通过，原 App 可继续正确加载旧数据的迁移版本及新 V3.1 原生曲包。
- [ ] 提交内容清单、自动校验结果、必要的未完成项；**不得将占位词典或 4 张空谱卡宣称为“全量完成”**。

## 8. 推荐实施依赖顺序

1. **P1 · 规范和验证器**：落实和弦定义/配法/替代关系、音高拼写、指法/Barre/T、音高与节奏校验器。
2. **P2 · 全量基础数据**：生成 12 主音理论库，维护已验证常用配法、12 根音 Power Chord、开放与封闭位置；测试通过。
3. **P3 · 原生模块与播放器契约**：四大模块教学映射、五种指板视图、独立轨道/版本/循环/音量接口，统一老数据到新模型。
4. **P4 · 内容编译**：「每日练习」36 小节完整曲包，另补齐 V3.1 的其余 1–2 套示范包；内容和数据测试一起交付。
5. **P5 · 验收与交付**：关键 CI、曲包谱面校验、真机可用性与兼容覆盖安装验证；非阻塞问题短列明，不额外引入长期“评分验收期”。
