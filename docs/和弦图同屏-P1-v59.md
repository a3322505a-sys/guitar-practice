## P0 复现与基线

连接的 PKR110，序列号 `70f1f09d`，v58 / `3.3.3-local10`，物理分辨率 1264×2780，density 560，系统字体 0.9。在 D 和弦上复现：初始顶部 X/O 可见、底部 6→1 弦号不可见；向上滚动图形后弦号出现，顶部 X/O 被裁切。证据：[初始 D](screenshots/v59-p1/baseline-d.png)、[滚动后的 D](screenshots/v59-p1/baseline-d-scrolled.png)。

源码证据：原布局在 `PracticeApp` 图形视口上设置 `weight(1f)`，却将 Canvas 高度取为 `maxOf(minimum * fontScale, maxHeight)`，其中 compact 的 minimum 为 176dp。高度超过剩余视口时，图内 verticalScroll 使顶部与底部交替可见。`ChordDiagram` 已将格线、点位、X/O、品号、实际音名及弦号统一绘制；本阶段无需修改绘图内部。截图与源码支持这个原因，不能据此排除所有设备和字体配置下的其他问题。

通过当前编译后的 `Routes.scale` 导出四对相邻型在 C 大调及 A 自然小调下的弦品/MIDI；使用整型音域、每拍 1 音、全六弦，无反向。见 [内容基线](p0-content-baseline-v59.txt)。同一程序确认 S01 的 16 音、4 段、96 tick；准备一小节 C3–D3–E3–F3、四个四分音符、`sections=[]` 的单音样例，模型构造成功。该样例没有加入正式曲库；原 UI 对 `sections[0]` 的依赖仍待 P4 处理。路线与短句数据在 P1 保持不变。

## P1 改动

- 手机和弦页合并重复的摘要入口，保留「和弦学习 / 短句应用 / 练习」以及短句标题和段落。和弦名、组成音、听和弦仍在主卡顶部。
- 和弦 Canvas 高度直接以真实视口为上限，不再增加最小图高并在图内纵向滚动。沿用现有等比绘制及触摸几何。
- 窄窗口可用高度不足 `600dp × fontScale` 时，为整页提供同高度的内容空间，页面整体滚动，播放控制保持在底部。普通手机竖屏优先完整同屏。
- 音阶图和 TAB 的原尺寸策略保留；默认指板竖屏，点击 TAB 横屏，点击指板回竖屏。播放器、素材、包名、数据及长期签名不变。
