# 常驻练习工作台 v80

2026-10-14；v80 / 4.0.0-local32。基于远端 main `0c698e9`，同时包含本地 v79 `7b07fbc` 的统一六线谱修复。开工时远端无开放 PR，main 最近 CI 成功；工作区干净。

本轮仅调整现有 UI、覆盖层协调与必要的显示适配，音乐内核、音频、曲包协议和用户数据格式不变。

## 入口变化

| 原入口 | 现入口 |
| --- | --- |
| 音阶/和弦、和弦学习/短句应用、练习设置 | 顶部当前内容摘要 → 内容 → 音阶练习/和弦学习/短句练习 |
| 调性、指型、练法 | 内容 → 音阶；新增由同一 ScaleOptions 派生的常用组合匹配 |
| 音域、每拍音数、起始级数 | 内容 → 音阶 → 高级；原适用条件保留 |
| 目录/版本、小节范围、轨道 | 内容 → 短句；目录在前，版本/选段/轨道按需展开 |
| 独立速度设置页 | 工作台底部 −5/数值/+5；点数值原位展开滑块，原谱模式调整倍率 |
| 次数、速度模式、声音 | 配置层的跟练/声音 Tab；没有重复速度控件 |
| 曲包导入/停用/回退、图示帮助 | 右上齿轮 → 全屏管理与帮助 |
| 和弦上下切换、听和弦、点音 | 图示区域；仍保留整卡横滑 |

手机竖屏配置层默认部分展开，底层实际图示压缩到其上方，遮罩透明度 8%；可上拖展开、下拖/返回/完成关闭。矮横屏与宽窗口在右侧显示配置，工作台使用剩余宽度；矮屏将视图控件并入摘要行，给谱面留出高度。工作台内容保持同一组合位置，打开/关闭面板不重置选择或播放器。

统一覆盖层状态为 NONE/PRACTICE/MANAGEMENT。L2 Tab 与展示折叠操作不结束播放；实际内容、速度、次数、选区、轨道变更沿用 invalidate；声音开关即时生效。速度拖动只更新局部预览，松手提交。点音在暂停的练习期间禁用，避免覆盖待继续的会话。

播放栏按真实 Phase 和 session.preview 派生：空闲开始跟练/听示范，准备中禁止重复开始，播放暂停/重来/结束，暂停继续，结束再练一次，试听只标试听；空闲无结束。错误保留原因和结束恢复操作。曲包安全检查、取消、提交保护、停用/回退及刷新逻辑沿用原 Repository。
