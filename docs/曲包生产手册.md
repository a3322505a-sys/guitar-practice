# 曲包生产与导入

生产工具在 scripts/song-package.py、scripts/song_package/，协议在 contracts/song-package/v1/。不需要 Android 源码；打包产物不含执行代码。开发/真机验收边界见《音乐内核与曲包施工记录》。

## 标准流程

~~~powershell
python -m pip install -r scripts/song_package/requirements.txt
python scripts/song-package.py inspect --source <原件> --output <新检查目录>
python scripts/song-package.py normalize --manifest <选材清单.json> --source <原件> --output <新候选目录>
python scripts/song-package.py validate --candidate <审核目录> --capabilities contracts/song-package/v1/capabilities.json
python scripts/song-package.py pack --candidate <审核目录> --output <新文件.gpractice> --capabilities contracts/song-package/v1/capabilities.json
~~~

所有输出目录/文件保护非覆盖；成功 exit 0，输入/兼容阻断 exit 2。inspect/normalize/validate/pack 返回结构化结果，未知音乐会指出位置。旧 song-assets.py 及歌曲Kotlin生成器已明确归档在 scripts/archive/legacy-v76，不属于当前生产流程；新增歌曲用曲包，不增加歌曲专属 Kotlin emitter、Phrases 注册或播放器。

1. 保留原件，绑定 sourceSha256，清点轨/声部/页码和排除范围。
2. 清单选择完整乐句和实际来源轨，注明许可、教学目标与版本关系。
3. normalize 生成书面 score、practices、provenance 与待审核模板；保留未知/近似项，不能把缺失来源填为休止。
4. 独立重读原谱/既有源 CSV，填写 reviewer、method、覆盖、定位和结论，保存 review.json。不能只用同一生成器往返作音乐证明。
5. validate/pack 重算结构、引用、能力、预算和覆盖；绑定原始 JSON 字节 SHA。修改审核对象后必须重新审核；同修订不同内容会被 App 拒绝。
6. App 的练习设置 → 本地曲库 / 导入歌曲 → 系统选择 .gpractice → 预览 → 导入/应用更新。导入后复制到私有存储，无需保留原 URI；原包删除不影响曲库。此流程使用 [Android SAF](https://developer.android.com/training/data-storage/shared/documents-files)。

## 来源格式边界

- GP：当前通用读取入口支持包含 Content/score.gpif 的 GP7/8 ZIP；读取六弦调弦/整夹、选择声部、拍号、已识别节奏/奏法/反复、来源定位。不伪装支持所有 GP 版本或所有符号。未知/未映射字段明确阻断，选择范围外记号归入排除范围。GP3–6 可用已有 Guitar Pro 导出 GP7/8 后对照原件，或用完整 canonical v1 数据转录路径。
- GP 源对象/重复引用实例是身份来源，不按 onset 注册 ID。发布修订需保持清单中的稳定 ID，并检查来源定位；重新导出导致 ID/路线变化时，App 只迁移可核锚点，否则恢复整句。
- PDF：完整转录入口是绑定 sourceSha256 的 {score,mappings}，score 使用全部 v1 节奏/声部能力，mappings 给页码/区域。旧 Your Trip 已审核转录格式作为兼容输入，实际转换不跳过 grace/bend/legato 等字段。不能承诺任意 PDF 自动无误。
- GP 的滑音/连线与弯音数值映射可对照 [alphaTab GPIF 读取实现](https://github.com/CoderLine/alphaTab/blob/develop/packages/alphatab/src/importer/GpifParser.ts)；本工具有自己的封闭字段检查和曲包契约。
- 首版不导入 RSE、音源、拾音器、录音、歌词/出版排版或非目标乐器。音色和力度/装饰近似必须披露，不能掩盖音高/节奏/曲序未知。

## 清单和原创样本

空白模板：contracts/song-package/v1/selection-template.json。原创独立样本：fixtures/ 下 simple、complex、nested、techniques、ties、harmonics、swing、strum、pickup、conditional、cross-tuplet、multi-track、shared；它们不是源曲正确性的证明。无效共用包在 fixtures/invalid/。

Review.status=conditional 不等于音乐经过条件 condition；前者是来源审核状态，后者是有界 Form 决定的音乐语义。将 source.repeat-count/source.coverage 假设明示到受影响练习，App 预览与练习说明均可见。

运行 Python 资产/曲包测试与 Android 来源回归；使用相同已安装 APK 实际导入未编进源码的新包，再验证离线重启、范围/设置、更新/回退和失败隔离。构建、程序播放和截图不能替代真机、试听、实弹或严格音画验收。
