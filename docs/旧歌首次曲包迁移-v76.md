## 迁移对象与数据

《嘘月》S01 是 v75 已有的 10–11 小节伴奏改编，只有一个教学版本。本轮转换既有 Kotlin 数据，不补录或推断完整原曲。16 个八分事件、六弦标准调弦、无夹、80 BPM 来源速度、4/4 两小节、四套低音/高音指法、实际力度、延响到同弦再拨或和弦切换/句尾的边界，以及标题、来源、难度、分类、技法、练习目标、建议速度和人工说明均进入五文件 v1 曲包。

`scripts/migrate-usotsuki.py` 固定读取上述 Git 源码与和弦数据，复用现有 `song_package.protocol` 生成和验证。交付 `output/usotsuki-v1.gpractice`，包 ID `local.usotsuki`，练习 ID `bass-treble`，修订 1。文件未放入 App assets，无自动预装或另一套加载路径。`app/src/test/resources/usotsuki-v1.gpractice` 仅为针对性检查使用，不打入 APK。

已删除 `Phrases.usotsuki` 歌曲数据与 `Phrases.all` 的 S01 专属注册。四张共用基础和弦卡原样保留；《斜阳》《卡夫卡》《Your Trip》《七个Block》、莫扎特、原创短句与基础教学仍使用原路径。测试目录保留一份 v75 S01 冻结数据用于独立对比，不是运行时素材。

## 数据连接与设置

Repository 从曲包 voicings/tracks 生成原有 `Chord` 卡，传入现有选择器、整卡滑动和逐弦播放。弦品/用指/调弦来自曲包；只有名称、弦品、调弦和夹位与已有指法完全相同才复用既有根音/三音分析，其他来源只显示已知按法，不猜和弦分析。包和指法 ID 作为选择身份，避免同名卡混淆。

PracticeSpec 的标题、目标、标签、建议速度、familyId/variantOf 与现有 Phrase/版本入口相连。包摘要中的完整教学说明也显示在练习信息中；旧目录缓存缺少新教学字段时从其原曲包读取，不改变旧缓存/索引哈希。

受控映射 S01 → `PracticeKey(local.usotsuki,bass-treble)`。导入并准备后复制原速度、次数和小节索引到现有曲包设置/来源锚点，沿用固定速度模式，保留旧键。旧选中 S01 而曲包尚未导入时记录待恢复选择并暂用 M01；用户明确选别的练习可覆盖待恢复选择。未迁移歌曲及旧 alias 路径不变。外部曲包 alias 仍只在自己的包命名空间内生效。

## 取消、提交与清理

可取消阶段包含输入、解析、预览、提交前重新验证及哈希检查。最后一道检查与用户取消共用小型同步门：先收到取消就不发布；先通过门就进入不可中断的短提交阶段。提交期间不再提供取消/关闭按钮，返回 UI 的结果也由 NonCancellable 保护，防止已写入索引的成功结果在协程切回主线程时被丢弃。

不可变文件/目录元数据继续先发布，活动索引继续 AtomicFile 原子写入；失败不会激活半写入歌曲。临时 pending 文件在 finally 删除。候选在预览取消、关闭/销毁弹窗、提交失败、提交前取消及成功后均清理；prepare 在写完 staging 后被取消也会清理，IO 返回过程中被取消的候选由持有者 finally 回收。

启动和曲库 reload 只清理 staging 直属目录里符合现有 UUID.gpractice 命名的、没有进程内候选占用的文件；目录和文件的 canonical 路径必须仍在预期位置。已提交修订、不相符文件、当前候选和指向其他位置的链接不删除。进程重启后的遗留 staging 因没有活跃占用可被回收。

## 针对性验证与手机验收

仅沿用既有 JUnit/Robolectric，补两个 Repository 检查并调整受迁移影响的原检查，没有新框架、CI 或全量回归。核对五文件包解析、手动导入所用 Repository 链路、音乐事件及生成 PCM 相等、四套卡、旧设置恢复、重新加载、v75 缓存、取消门、取消/失败清理、活跃预览保护与孤立 staging 回收。使用既有界面检查核对导入后的指法/短句选择。Release 构建和原流程签名另存本地日志。

手机重点验收：

1. 覆盖安装 v76；在本地曲库选交付曲包，先取消预览/关闭，再确认曲库没有新增歌曲；重新选包后能正常导入。
2. 导入后进入《嘘月》短句，看两小节 TAB、四段指法、教学说明，听示范/跟练，并切换指板与六线谱。和弦学习中检查本地曲库四张指法卡、点音与逐弦播放。
3. 若原来用过 S01，核对速度、次数、选区与选中状态；改设置后重启 App，核对恢复及离线可用。
4. 在检查阶段取消，应保持未导入；遇到“正在完成导入”应等待实际完成，不能出现界面称取消而曲库新增。清理内部 staging 由针对性文件检查证明，手机主要观察反复取消/重试不影响有效歌曲。
5. 抽查一首未迁移歌曲及基础练习，确认原有入口、和弦和播放仍可用。

尚未替代手机系统文件选择器、真实安装后的使用、主观试听、实弹和音画同步验收。此次《嘘月》只覆盖原有两小节改编，未承诺完整原曲。
