# Electric guitar multisamples

Source: FreePats, Electric Guitar FSBS Clean #1, bridge small, 2026-08-07.
https://github.com/freepats/electric-guitar-FSBS-clean
https://freepats.zenvoid.org/ElectricGuitar/clean-electric-guitar.html

Released by the sample publisher under CC0 1.0; full license included.
Recorded Fender electric guitar processed to a clean amplified sound.
Derived assets: first 4 seconds, mono PCM16 LE, 22050 Hz, 25 Hz high-pass.
Filenames are original MIDI key centers, following the publisher's small SFZ mapping:
36 C2; 41 F2; 45 A2; 48 C3; 52 E3; 55 G3; 59 B3; 64 E4; 67 G4;
71 B4; 74 D5; 80 G#5; 85 C#6. Runtime selects the nearest key center and
resamples at the exact equal-tempered ratio. No network is used by the App.

Runtime gain is calibrated on the first 360 ms, peak-limited before mixing,
then mixed with square-root voice compensation and common peak headroom.
Original instrument identity and source version are retained here; playback
quality on the user's device remains subject to listening verification.
