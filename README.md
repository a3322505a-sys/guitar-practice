# 吉他练习

自用的离线 Android 吉他练习 App，支持音阶、和弦、歌曲与短句练习。采用全宽联动指板/六线谱、底部播控及独立内容库与偏好。

当前开发版本 **1.1.1 / 106**，从 V105 新分支原生重制。四个并列模块：基础启蒙、和弦教学、音阶教学、综合应用。内置 86 条标准练习记录，另有 C/Am、Capo 2、J-Rock 三个原创满配示范曲包，支持原谱/新手版本、独立领奏/伴奏、明确衔接、Solo 倒序接龙与练前热身。

旧曲包、SevenBlocks/Kernel 和旧 ID 兼容链已移除，当前数据完整编写并由独立审计检查。App 保持单一 alphaTab 播放/谱面时间轴。内容与验证边界见 [V106 原生数据记录](docs/原生教学数据-v106.md)，构建入口见 [compare 变体](docs/build-variants.md)。
