# 吉他练习

自用的离线 Android 吉他练习 App，支持音阶、和弦、歌曲与短句练习。采用全宽联动指板/六线谱、底部播控及独立内容库与偏好。

练习内容支持「基础训练 + 曲包」筛选，和弦与歌曲页共享来源记忆；莫扎特 K265 收入基础单音训练。界面与验证记录见 [v101 内容面板](docs/练习内容面板-v101.md)。

当前开发版本 **1.0.1 / 103**。基础和弦与短句按教学目标分组，音阶提供五个独立小节；指法图增加紧凑图例与有数据依据的横按，普通下一音使用细环预告。实施及验收见 [教学化 UI](docs/教学化UI-P1-P8.md)。工作区入口、构建方式及文档分类见 [开发索引](docs/README.md)；基线审计与保留项见 [工作区整理记录](docs/工作区整理-1.0.0.md)。
