# 吉他练习

自用的离线 Android 吉他练习 App，支持音阶、和弦、歌曲与短句练习。采用全宽联动指板/六线谱、底部播控及独立内容库与偏好。

练习内容支持「基础训练 + 曲包」筛选，和弦与歌曲页共享来源记忆；莫扎特 K265 收入基础单音训练。界面与验证记录见 [v101 内容面板](docs/练习内容面板-v101.md)。

当前开发版本 **1.1.0 / 105**。教学入口分为基础启蒙、和弦教学、音阶教学和综合应用；调速统一显示 BPM，播放栏提供独立的节拍/音乐音量。新旧教学内容共用标准曲包与 alphaTab 时间轴；F/Bm/G 的简化替代在同一入口切换，综合应用可直达两组双轨渐隐领奏与倒序接龙。需求见 [V3.1 规范](docs/教学体系-V3.1.md)，实现与实际验收边界见 [实施记录](docs/教学体系-V3.1-实施记录.md)。工作区、构建及文档入口见 [开发索引](docs/README.md)。
